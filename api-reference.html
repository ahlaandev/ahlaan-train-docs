Storage & file downloads ​

To download any uploaded document (SPK, KTP, NIB, payment/transfer proofs, generated tickets) by its File.id, see Storage — Download a File by ID. It documents all four storage download routes, the owner-or-admin access model, presigned /url links, and the shareable no-login token flow.
