API Endpoints ​

Complete reference for all WhatsApp management API endpoints.

Device Configuration ​

GET /config/device-id ​

Get the current device ID configuration.

Response:

json
{
  "deviceId": "628123456789@s.whatsapp.net",
  "source": "database",
  "isConfigured": true
}

Fields:

FieldTypeDescription
deviceIdstringThe current device ID (empty if not configured)
sourcestringSource of configuration: database, environment, or none
isConfiguredbooleanWhether a device ID is configured

PUT /config/device-id ​

Set or update the device ID in the database.

Request Body:

json
{
  "deviceId": "628123456789@s.whatsapp.net"
}

Validation Rules:

  • Device ID must end with @s.whatsapp.net
  • Cannot be empty or null
  • Must be a string

Response:

json
{
  "success": true,
  "message": "Device ID updated successfully",
  "deviceId": "628123456789@s.whatsapp.net"
}

Error Response (400):

json
{
  "statusCode": 400,
  "message": "Device ID must end with @s.whatsapp.net",
  "error": "Bad Request"
}

DELETE /config/device-id ​

Clear the device ID from the database. The service will fall back to the environment variable if set.

Response:

json
{
  "success": true,
  "message": "Device ID cleared from database"
}

Device Management ​

GET /devices ​

List all registered WhatsApp devices from the GoWA service.

Response:

json
{
  "status": 200,
  "code": "SUCCESS",
  "message": "Devices retrieved successfully",
  "data": [
    {
      "device_id": "628123456789@s.whatsapp.net",
      "phone_number": "628123456789",
      "connected": true,
      "loggedIn": true
    }
  ]
}

When GoWA is unavailable:

json
{
  "status": 200,
  "code": "SUCCESS",
  "message": "No devices registered or GoWA service not available",
  "data": []
}

POST /devices ​

Add a new WhatsApp device to the GoWA service.

Request Body:

json
{}

Response:

json
{
  "status": 200,
  "code": "SUCCESS",
  "message": "Device created successfully",
  "device_id": "628123456789@s.whatsapp.net",
  "phone_number": "628123456789"
}

When GoWA is unavailable (503):

json
{
  "statusCode": 503,
  "message": "GoWA service is not available or does not support device management",
  "error": "Service Unavailable"
}

GET /devices/:deviceId ​

Get information about a specific device.

URL Parameters:

ParameterTypeDescription
deviceIdstringThe device ID (URL encoded)

Example:

bash
GET /admin/whatsapp/devices/628123456789%40s.whatsapp.net

Response:

json
{
  "status": 200,
  "code": "SUCCESS",
  "message": "Device info retrieved",
  "device_id": "628123456789@s.whatsapp.net",
  "phone_number": "628123456789",
  "connected": true,
  "loggedIn": true
}

GET /devices/:deviceId/status ​

Get the connection status of a specific device.

Response:

json
{
  "status": 200,
  "code": "SUCCESS",
  "message": "Device status retrieved",
  "connected": true,
  "loggedIn": true,
  "phone_number": "628123456789"
}

Fields:

FieldTypeDescription
connectedbooleanWhether the device is connected to GoWA
loggedInbooleanWhether the device is logged into WhatsApp
phone_numberstringThe phone number associated with the device

POST /devices/:deviceId/remove ​

Remove a device from the GoWA service.

Response:

json
{
  "status": 200,
  "code": "SUCCESS",
  "message": "Device removed successfully"
}

Device Authentication ​

GET /devices/:deviceId/login ​

Initiate QR code login flow for a device.

Response:

json
{
  "status": 200,
  "code": "SUCCESS",
  "message": "QR code generated",
  "qr_code": "data:image/png;base64,iVBORw0KGgo..."
}

Already Logged In:

json
{
  "status": 200,
  "code": "ALREADY_LOGGED_IN",
  "message": "Already logged in - session is active"
}

POST /devices/:deviceId/login-code ​

Generate a pairing code for phone number login.

URL Parameters:

ParameterTypeDescription
deviceIdstringThe device ID
phonestringPhone number for pairing (query param)

Example:

bash
POST /admin/whatsapp/devices/628123456789%40s.whatsapp.net/login-code?phone=628123456789

Response:

json
{
  "status": 200,
  "code": "SUCCESS",
  "message": "Pairing code generated",
  "pairing_code": "K241-9XYZ"
}

POST /devices/:deviceId/logout ​

Logout a device from WhatsApp.

Response:

json
{
  "status": 200,
  "code": "SUCCESS",
  "message": "Device logged out successfully"
}

POST /devices/:deviceId/reconnect ​

Attempt to reconnect a device to WhatsApp.

Response:

json
{
  "status": 200,
  "code": "SUCCESS",
  "message": "Reconnection initiated"
}

Legacy Endpoints (Deprecated) ​

These endpoints are maintained for backward compatibility but should not be used for new implementations:

  • GET /admin/whatsapp/status - Use /devices/:deviceId/status instead
  • GET /admin/whatsapp/login - Use /devices/:deviceId/login instead
  • GET /admin/whatsapp/login-with-code - Use /devices/:deviceId/login-code instead
  • POST /admin/whatsapp/logout - Use /devices/:deviceId/logout instead
  • POST /admin/whatsapp/reconnect - Use /devices/:deviceId/reconnect instead
