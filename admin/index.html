Admin Guides ​

Welcome to the HHR admin documentation. These guides explain how administrators configure the system for B2B operations.

Overview ​

The admin APIs allow you to configure:

  • Booking Management - View all bookings, reports, and resend cancellation emails
  • WhatsApp Management - Manage WhatsApp devices and GoWA configuration
  • Pricing & Markup - Markup and discount rules for bookings
  • Fare Preferences - Default fare types for each cabin class
  • Railway Stations - HHR train stations referenced by tariffs and custom route prices (replaces the deprecated "Locations" admin under tariffs)
  • Tariffs - Fixed pricing for B2B group bookings
  • Pricing Configuration - Child/infant percentage rules
  • Mitra Pricing - Mitra-host child-to-adult sell-price ratio (silver/gold, both cabins)
  • Tax Rules - VAT/tax configuration for bookings
  • Payment Gateways - Payment gateway configuration and management
  • Payment Gateway Fees - Transaction fee rules per payment method
  • Banks - Supported Indonesian banks for wallet top-ups
  • Office Locations - Physical Ahlaan offices used by the in-person (cash) payment rail
  • System Configuration - System-wide settings and feature flags
  • Invoice Management - Create and manage invoices
  • Payment Management - Refunds, webhooks, and payment reconciliation
  • Wallet Management - User wallets and withdrawal requests
  • B2B Applications - Approve/reject B2B partner applications
  • Organizations Management - List, create, update, deactivate B2B organizations and clean up orphans
  • Admin Roles - Manage admin roles and permissions
  • Exchange Rate - Manage currency exchange rates
  • Financial Reports - Revenue, transactions, wallets, refunds, and tax reports
  • Notification Management - Send and manage user notifications
  • Custom Booking Management - Status state machine, ticket upload, and auto-complete cron
  • Ticket Channels - Manage ticket-issuing channels (HHR, etc.) referenced by custom bookings
  • Audit Logs - Browse, filter, and export the automatic audit trail of every admin mutation
  • Admin Password Reset - Public self-service OTP flow for admins who have lost access to their credentials

Quick Start ​

Authentication ​

All admin endpoints require:

  • JWT Token in Authorization header
  • ADMIN role in user account
http
Authorization: Bearer <your-admin-jwt-token>

Exception: the Admin Password Reset endpoints are intentionally public so an admin who has lost their credentials can recover access. They are throttled instead of guarded.

Base URL ​

/api/v1

Quick Example ​

1. Create a Railway Station ​

bash
curl -X POST /api/v1/admin/railway-stations \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "code": "DMX",
    "name": "Madinah",
    "isActive": true
  }'

The legacy path /api/v1/admin/tariffs/locations still works but is deprecated.

2. Create a Tariff ​

bash
curl -X POST /api/v1/admin/tariffs \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "originId": "<location-id-dmx>",
    "destinationId": "<location-id-mkx>",
    "tripClass": "ECONOMY",
    "tripType": "ONE_WAY",
    "price": 150.00,
    "isActive": true
  }'

3. Configure Pricing ​

bash
curl -X POST /api/v1/admin/tariff-pricing-config \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "childPricePercentage": 75,
    "infantPricePercentage": 0
  }'

Seeded Data Summary ​

The following data is seeded automatically:

Pricing Rules ​

  • Base Markup (All Customers): 10% markup for all bookings

Tax Rules ​

  • VAT 11%: Applied to all bookings on final amount

Railway Stations ​

  • 4 stations: DMX (Madinah), MKX (Makkah), JXD (Jeddah), KCX (KAEC)

Tariffs ​

  • 48 tariffs: All route combinations × 2 trip classes × 2 trip types
  • Price: 250 SAR per route

Payment Gateways ​

  • Xendit: Active (BANK_TRANSFER only at runtime)
  • Midtrans: Inactive (backup gateway)
  • Stripe: Inactive (international cards)

Payment Gateway Fees (Xendit) ​

  • QRIS: 0.65%
  • Bank Transfer: Fixed 4,000 IDR
  • E-Wallet: 1.5% (min 1,500 IDR)

Indonesian Banks ​

  • 14 banks including BCA, BNI, BRI, Mandiri, etc.

System Configuration ​

  • Fee Display Mode: COMBINED
  • Payment Gateway Fees: Disabled
  • Tax: Enabled, inclusive pricing
  • Wallet Top-up: Enabled with Xendit as default
  • Wallet Top-up Currencies: IDR and SAR only
