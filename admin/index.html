Admin Guides ​

Welcome to the HHR admin documentation. These guides explain how administrators configure the system for B2B operations.

Overview ​

The admin APIs allow you to configure:

  • Locations - HHR train stations for tariff routing
  • Tariffs - Fixed pricing for B2B group bookings
  • Pricing Configuration - Child/infant percentage rules

Quick Start ​

Authentication ​

All admin endpoints require:

  • JWT Token in Authorization header
  • ADMIN role in user account
http
Authorization: Bearer <your-admin-jwt-token>

Base URL ​

/api/v1

Quick Example ​

1. Create a Location ​

bash
curl -X POST /api/v1/admin/tariffs/locations \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "code": "DMX",
    "name": "Madinah",
    "isActive": true
  }'

2. Create a Tariff ​

bash
curl -X POST /api/v1/admin/tariffs \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "originId": "<location-id-dmx>",
    "destinationId": "<location-id-mkx>",
    "tripClass": "ECONOMY",
    "tripType": "ONE_WAY",
    "price": 150.00,
    "isActive": true
  }'

3. Configure Pricing ​

bash
curl -X POST /api/v1/admin/tariff-pricing-config \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "childPricePercentage": 75,
    "infantPricePercentage": 0
  }'
