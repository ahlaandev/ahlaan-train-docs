Scraper Search Integration ​

The Scraper Search module exposes a single read-only endpoint that returns the raw, untransformed OTA_AirLowFareSearchRS body for a given route and date. It is intended for external scrapers that need the supplier response exactly as received — with no caching, pricing, markup, tax, or B2B transformation applied.

Quick Overview ​

FeatureDescription
PurposeReturn the raw OTA low fare search response for scrapers
AuthenticationAPI Key (X-Api-Key header), validated against SCRAPER_ACCESS_API_KEY
EndpointGET /api/v1/scraper-search/air-low-fare-search
Rate Limit100 req/min
CachingNone — every request hits the supplier live
TransformationNone — raw OTA_AirLowFareSearchRS body returned as-is
Empty resultReturns {} when the supplier reports no availability

Authentication ​

The endpoint requires a dedicated API key passed via the X-Api-Key header:

http
X-Api-Key: <your-scraper-access-api-key>

The key is validated against the SCRAPER_ACCESS_API_KEY environment variable. It is intentionally separate from the internal service key so that scraper access can be rotated or revoked independently.

The guard fails closed: if SCRAPER_ACCESS_API_KEY is unconfigured, or the supplied key is missing or incorrect, the request receives a 401 Unauthorized response.

Endpoint ​

Air Low Fare Search ​

Endpoint: GET /api/v1/scraper-search/air-low-fare-search

Runs an OTA low fare search with the supplied query parameters and returns the raw OTA_AirLowFareSearchRS body.

Query Parameters:

ParameterTypeRequiredDescription
originstringYesOrigin station code. Exactly 3 chars, trimmed and upper-cased (e.g. DMX).
destinationstringYesDestination station code. Exactly 3 chars, trimmed and upper-cased (e.g. MKX).
departureDatestringYesDeparture date, YYYY-MM-DD.
returnDatestringConditionalReturn date, YYYY-MM-DD. Required when tripType=ROUND_TRIP, otherwise omit.
adultsintegerYesNumber of adults. Range 1–9.
childrenintegerYesNumber of children. Range 0–9.
infantsintegerYesNumber of infants. Range 0–9.
tripTypeenumYesONE_WAY or ROUND_TRIP.

Example Request (one-way):

http
GET /api/v1/scraper-search/air-low-fare-search?origin=DMX&destination=MKX&departureDate=2026-05-30&adults=1&children=0&infants=0&tripType=ONE_WAY
X-Api-Key: <your-scraper-access-api-key>

Example Request (round-trip):

http
GET /api/v1/scraper-search/air-low-fare-search?origin=DMX&destination=MKX&departureDate=2026-05-30&returnDate=2026-06-05&adults=2&children=1&infants=0&tripType=ROUND_TRIP
X-Api-Key: <your-scraper-access-api-key>

Responses:

StatusDescription
200Raw OTA_AirLowFareSearchRS body, or {} when no availability was returned.
400Invalid query parameters (e.g. bad station code length, missing returnDate for ROUND_TRIP, out-of-range passenger count).
401Invalid or missing API key.

The 200 body is the supplier response verbatim. When the supplier reports no availability (or returns a 4xx), the endpoint normalizes the result to an empty object {} so the response is always valid JSON.
