Exchange Rate Management Guide ​

This guide explains how administrators can manage currency exchange rates for the HHR platform.

Quick Overview ​

FeatureDescription
PurposeManage IDR to SAR exchange rates for wallet top-ups
AccessAdmin only
ScopeAll currency conversions

Base URL ​

All exchange rate endpoints use:

/api/v1

Authentication ​

All exchange rate endpoints require:

  • JWT Token in Authorization header
  • ADMIN role in user account
http
Authorization: Bearer <your-admin-jwt-token>

How Exchange Rates Work ​

Exchange Rate Flow ​

┌─────────────────────────────────────────────────────────────────┐
│                    EXCHANGE RATE FLOW                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  1. System fetches rates from external API                       │
│     - Buy rate: Bank buys IDR from you (lower)                   │
│     - Sell rate: Bank sells IDR to you (higher)                  │
│                        ↓                                         │
│  2. Rates are cached in Redis for 1 hour                         │
│                        ↓                                         │
│  3. Wallet top-up uses sell rate:                                │
│                                                                  │
│     Input: 500,000 IDR (QRIS payment)                           │
│     Sell Rate: 15,000 IDR/SAR                                   │
│     ─────────────────────────────────────                        │
│     Gross SAR = 500,000 ÷ 15,000 = 33.33 SAR                    │
│                                                                  │
│  4. Tax calculation:                                             │
│                                                                  │
│     Gross SAR: 33.33                                            │
│     Tax (11%): 3.66 SAR                                         │
│     ─────────────────────────────────────                        │
│     Net SAR (credited): 29.67 SAR                               │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Rate Types ​

TypeDescriptionUsage
Buy RateBank's rate to buy foreign currencyNot currently used
Sell RateBank's rate to sell foreign currencyUsed for wallet top-ups

Endpoints ​

1. Get Exchange Rate History ​

Endpoint: GET /admin/exchange-rate/history

Get paginated exchange rate history.

Query Parameters:

ParameterTypeDescription
currencystringFilter by currency (default: SAR)
pagenumberPage number (default: 1)
limitnumberItems per page (default: 20)

Example:

bash
GET /admin/exchange-rate/history?currency=SAR&page=1&limit=20

Response: 200 OK

json
{
  "data": [
    {
      "id": "rate-uuid",
      "currency": "SAR",
      "buyRate": 14850.00,
      "sellRate": 14925.00,
      "fetchedAt": "2026-01-31T10:00:00Z",
      "source": "EXTERNAL_API",
      "isActive": true
    }
  ],
  "meta": {
    "total": 1000,
    "page": 1,
    "limit": 20,
    "totalPages": 50
  }
}

2. Manual Sync Exchange Rate ​

Endpoint: POST /admin/exchange-rate/sync

Manually trigger exchange rate sync from external API.

Use cases:

  • Rates seem outdated
  • Automatic sync failed
  • Need fresh rates before large top-ups

Response: 200 OK

json
{
  "success": true,
  "message": "Exchange rate synced successfully",
  "rate": {
    "id": "rate-uuid",
    "currency": "SAR",
    "buyRate": 14850.00,
    "sellRate": 14925.00,
    "fetchedAt": "2026-01-31T12:00:00Z",
    "isActive": true
  }
}

Error Response: 400 Bad Request

json
{
  "statusCode": 400,
  "message": "Failed to fetch exchange rate from external API",
  "error": "External API unavailable"
}

Automatic Sync ​

The system automatically syncs exchange rates:

SettingValue
FrequencyEvery 1 hour
SourceExternal currency API
CacheRedis (1 hour TTL)
FallbackLast known rate if API fails

Rate Calculation Examples ​

Example 1: Basic Wallet Top-Up ​

User pays: 500,000 IDR via QRIS
Sell Rate: 15,000 IDR/SAR

Gross SAR = 500,000 ÷ 15,000 = 33.33 SAR
Tax (11%) = 33.33 × 0.11 = 3.67 SAR
────────────────────────────────────
Net Credited = 33.33 - 3.67 = 29.66 SAR

Example 2: Large Top-Up (Tax Exempt) ​

User pays: 10,000,000 IDR
Sell Rate: 15,000 IDR/SAR
Tax Exempt: Yes (verified business)

Gross SAR = 10,000,000 ÷ 15,000 = 666.67 SAR
Tax (11%) = 0 SAR (exempt)
────────────────────────────────────
Net Credited = 666.67 SAR

Example 3: Rate Change Impact ​

Same payment: 500,000 IDR

Old Rate: 14,500 IDR/SAR
Gross = 500,000 ÷ 14,500 = 34.48 SAR

New Rate: 15,500 IDR/SAR
Gross = 500,000 ÷ 15,500 = 32.26 SAR

Difference: 2.22 SAR less received

Exchange Rate Storage ​

Database Schema ​

sql
ExchangeRate {
  id: UUID (primary key)
  currency: String (e.g., "SAR")
  buyRate: Decimal (IDR per unit)
  sellRate: Decimal (IDR per unit)
  source: String (e.g., "EXTERNAL_API")
  isActive: Boolean
  fetchedAt: DateTime
}

Active Rate Selection ​

The system always uses the most recent active rate for calculations:

SELECT * FROM ExchangeRate
WHERE currency = 'SAR'
  AND isActive = true
ORDER BY fetchedAt DESC
LIMIT 1
