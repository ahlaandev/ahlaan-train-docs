Financial Reports ​

Comprehensive financial reporting for administrators to track revenue, transactions, wallets, refunds, and taxes.

Overview ​

The Financial Reports API provides detailed insights into your platform's financial performance. All reports support date range filtering and can be grouped by day, week, or month for trend analysis.

Available Reports ​

ReportDescriptionEndpoint
DashboardKey performance indicators (KPIs) summaryGET /admin/reports/dashboard
RevenueRevenue breakdown by method, route, and timeGET /admin/reports/revenue
TransactionsPayment transaction analysisGET /admin/reports/transactions
WalletsWallet balances and activityGET /admin/reports/wallets
RefundsRefund processing and policy breakdownGET /admin/reports/refunds
TaxVAT/tax collection reportsGET /admin/reports/tax

Authentication ​

All report endpoints require:

  • JWT Token in Authorization header
  • ADMIN role in user account
http
Authorization: Bearer <your-admin-jwt-token>

Common Parameters ​

Date Range ​

All report endpoints support date filtering via presets or custom ranges:

ParameterTypeDescription
presetstringPredefined range: TODAY, YESTERDAY, LAST_7_DAYS, LAST_30_DAYS, THIS_MONTH, LAST_MONTH, CUSTOM
fromstringStart date (ISO format: YYYY-MM-DD) - required when preset=CUSTOM
tostringEnd date (ISO format: YYYY-MM-DD) - required when preset=CUSTOM
groupBystringChart data grouping: day, week, month (default: day)

Pagination ​

List endpoints support pagination:

ParameterTypeDefaultDescription
pagenumber1Page number
limitnumber20Items per page (max: 100)

Policy Types ​

PolicyDescription
B2C_FULLB2C booking cancelled > 24h before departure (100% or 80% refund)
B2C_PARTIALB2C booking cancelled 20min-24h before departure (65% or 50% refund)

B2B_FULLB2B booking cancelled > 20 days before departure (100% refund)
B2B_NO_REFUNDB2B booking cancelled ≤ 20 days before departure (0% refund)
ADMIN_OVERRIDEManual admin adjustment

Filtering by Organization ​

Admin reports support filtering by organization for B2B partner analysis:

http
GET /api/v1/admin/reports/dashboard?preset=THIS_MONTH&organizationId=org-uuid-here

This filters all data to show only bookings, transactions, and refunds for the specified organization.

Caching ​

Report data is cached to improve performance:

ReportCache Duration
Dashboard5 minutes
Revenue2 minutes
Transactions2 minutes
Wallets2 minutes
Refunds2 minutes
Tax5 minutes

For real-time data, wait for the cache to expire or use a unique query parameter.
