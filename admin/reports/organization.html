Organization Reports (B2B self-service) ​

Reporting endpoints scoped to the caller's own organization. Unlike the admin financial reports (which aggregate across the whole platform), these are consumed by B2B organization users to see their own bookings, revenue, wallet, refunds, and tax.

The organization is resolved from the authenticated user's organizationId — there is no organizationId query parameter and no cross-organization access. A user not associated with an organization gets 403 Forbidden.

Tag note. In Swagger these routes share the 4. Admin - Reports tag with the admin hub, but the access role is B2B, not ADMIN — see Access.

Access ​

Base path/api/v1/reports/organization
AuthAuthGuard('jwt') — Bearer token required
RoleB2B (@Roles(UserRole.B2B))
ScopeThe caller's own organization (req.user.organizationId)

403 Forbidden — "User is not associated with an organization" — when the authenticated user has no organizationId.

Common query parameters ​

All endpoints except wallets accept a date range. transactions and refunds additionally accept pagination. revenue and tax accept a chart grouping.

ParamTypeApplies toDefaultNotes
presetenumdashboard, revenue, transactions, refunds, taxTHIS_MONTHTODAY, YESTERDAY, LAST_7_DAYS, LAST_30_DAYS, THIS_MONTH, LAST_MONTH, CUSTOM
fromISO datesame—Start date (e.g. 2026-01-01). Used with preset=CUSTOM.
toISO datesame—End date (e.g. 2026-01-31). Used with preset=CUSTOM.
groupByenumrevenue (day), tax (month)per-endpointday, week, month — chart bucket size
pagenumbertransactions, refunds1Page number
limitnumbertransactions, refunds20Items per page

wallets takes no query parameters — it returns the current wallet snapshot for the organization.

Endpoint detail ​

GET /dashboard ​

KPI summary card data for the selected period.

GET /api/v1/reports/organization/dashboard?preset=THIS_MONTH
Authorization: Bearer <b2b-jwt>

Returns { period: { from, to }, kpi: { ... } }.

GET /revenue ​

GET /api/v1/reports/organization/revenue?preset=LAST_30_DAYS&groupBy=day

Revenue summary, breakdown by payment method and route, and a chart series bucketed by groupBy (default day).

GET /transactions ​

GET /api/v1/reports/organization/transactions?preset=THIS_MONTH&page=1&limit=20

Paginated transaction list plus status/method counts and a chart series. Response includes totalPages and page.

GET /wallets ​

GET /api/v1/reports/organization/wallets

Wallet balances and activity for the organization. No date range.

GET /refunds ​

GET /api/v1/reports/organization/refunds?preset=THIS_MONTH&page=1&limit=20

Paginated refunds plus summary and policy breakdown. Response includes totalPages and page.

GET /tax ​

GET /api/v1/reports/organization/tax?preset=THIS_MONTH&groupBy=month

Tax summary, breakdown by route, and a chart series bucketed by groupBy (default month).

Example ​

bash
curl -X GET "https://<host>/api/v1/reports/organization/revenue?preset=THIS_MONTH&groupBy=day" \
  -H "Authorization: Bearer <b2b-jwt>"
