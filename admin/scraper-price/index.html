Scraper Price Integration ​

The Scraper Price module provides an API endpoint for external scrapers to submit competitor price data. This data is stored for historical analysis and comparison with HHR API search results.

Quick Overview ​

FeatureDescription
PurposeRecord price data from external scrapers for market comparison
AuthenticationAPI Key (X-Api-Key header) for scraper, JWT + Admin role for admin endpoints
Scraper EndpointPOST /api/v1/scraper/price-records
Admin CreatePOST /api/v1/admin/scraper-price/records
Rate Limit100 req/min (scraper), 10 req/min (admin create/update/delete)
StoragePrices stored as DECIMAL(10,2) in SAR

Valid Location Codes ​

Origin and destination codes must match existing Location entries in the system:

CodeLocation
DMXMadinah
JEDJeddah Airport
JXDJeddah Al-Sulimaniyah
KCXKing Abdullah Economic City
MKXMakkah

Codes are validated against the database. Requests with invalid codes will receive a 400 Bad Request response.

Authentication ​

All scraper endpoints require an API key passed via the X-Api-Key header:

http
X-Api-Key: <your-api-key>

Requests without a valid API key will receive a 401 Unauthorized response.

Endpoints ​

1. Create Price Record ​

Endpoint: POST /api/v1/scraper/price-records

Submit price data collected by an external scraper.

Request Body:

json
{
  "origin": "MKX",
  "destination": "DMX",
  "tripType": "ONE_WAY",
  "tripClass": "ECONOMY",
  "departureDate": "2026-05-15",
  "adultCount": 1,
  "childCount": 0,
  "infantCount": 0,
  "lowestPricePerAdult": 150.0,
  "meanPricePerAdult": 200.0,
  "highestPricePerAdult": 250.0,
  "scraperSource": "scraper-v1",
  "scrapedAt": "2026-04-08T10:30:00Z",
  "metadata": {
    "sampleSize": 10,
    "currency": "SAR",
    "notes": "Peak season pricing"
  }
}

Request Fields:

FieldTypeRequiredDescription
originstringYesOrigin location code (e.g., MKX)
destinationstringYesDestination location code (e.g., DMX)
tripTypeenumYesONE_WAY or ROUND_TRIP
tripClassenumYesECONOMY or BUSINESS
departureDateISO dateYesDeparture date (must be today or future in Asia/Riyadh timezone)
returnDateISO dateConditionalRequired for ROUND_TRIP, must not be provided for ONE_WAY
adultCountintegerYesNumber of adults (min: 1)
childCountintegerNoNumber of children (min: 0, default: 0)
infantCountintegerNoNumber of infants (min: 0, default: 0)
lowestPricePerAdultnumberYesLowest price found per adult in SAR (must be positive)
meanPricePerAdultnumberYesAverage price per adult in SAR (must be >= lowest)
highestPricePerAdultnumberYesHighest price found per adult in SAR (must be >= mean)
scraperSourcestringNoIdentifier for the scraper (e.g., scraper-v1, manual)
scrapedAtISO datetimeYesWhen the scraper collected this data
metadataobjectNoAdditional metadata (see below)

Metadata Object Fields:

Validation Rules ​

Location Validation ​

  • Origin and destination must match existing Location records in the database
  • Error: Invalid origin code: XYZ. No matching location found.
  • Error: Invalid destination code: XYZ. No matching location found.

Date Validation ​

  • departureDate must be today or a future date (evaluated in Asia/Riyadh timezone)
  • returnDate is required for ROUND_TRIP trips
  • returnDate must not be provided for ONE_WAY trips
  • returnDate must be strictly after departureDate (same-day returns are rejected)
ConditionError Message
Past departure datedepartureDate must be today or a future date
ROUND_TRIP without returnDatereturnDate is required for ROUND_TRIP trips
ONE_WAY with returnDatereturnDate should not be provided for ONE_WAY trips
returnDate <= departureDatereturnDate must be after departureDate

Price Validation ​

Prices must follow a logical ordering:

ConditionError Message
lowest > meanlowestPricePerAdult cannot be greater than meanPricePerAdult
mean > highestmeanPricePerAdult cannot be greater than highestPricePerAdult

Admin Endpoints (JWT + Admin Role) ​

All admin endpoints require JWT authentication and the ADMIN role.

http
Authorization: Bearer <your-admin-jwt-token>

2. Create Price Record (Admin) ​

Endpoint: POST /api/v1/admin/scraper-price/records

Create a single scraper price record via the admin panel. Uses JWT authentication instead of API key.

Rate Limit: 10 requests per 60 seconds.

bash
curl -X POST /api/v1/admin/scraper-price/records \
  -H "Authorization: Bearer <admin-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "origin": "MKX",
    "destination": "DMX",
    "tripType": "ONE_WAY",
    "tripClass": "ECONOMY",
    "departureDate": "2026-05-15",
    "adultCount": 1,
    "lowestPricePerAdult": 150.0,
    "meanPricePerAdult": 200.0,
    "highestPricePerAdult": 250.0,
    "scraperSource": "manual",
    "scrapedAt": "2026-04-08T10:30:00Z"
  }'

Request Body: Same fields as the scraper Create endpoint above. All validation rules apply.

Response: 201 Created — Same response format as Create above.

4. List Price Records ​

Endpoint: GET /api/v1/admin/scraper-price/records

List all scraper price records with optional filtering and pagination.

Query Parameters:

ParameterTypeDescription
originstringFilter by origin code
destinationstringFilter by destination code
tripTypeenumFilter by ONE_WAY or ROUND_TRIP
tripClassenumFilter by ECONOMY or BUSINESS
dateFromISO dateFilter departure dates from this date
dateToISO dateFilter departure dates up to this date
scraperSourcestringFilter by scraper source identifier
pagenumberPage number (default: 1)
limitnumberItems per page (default: 20)

Example:

bash
curl /api/v1/admin/scraper-price/records?origin=MKX&destination=DMX&limit=10 \
  -H "Authorization: Bearer <token>"

Response: 200 OK

  "data": [

5. Get Price Record by ID ​

Endpoint: GET /api/v1/admin/scraper-price/records/:id

bash
curl /api/v1/admin/scraper-price/records/01ARZ3NDEKTSV4RRFFQ69G5FAV \
  -H "Authorization: Bearer <token>"

Response: 200 OK — Same as Create response.

6. Update Price Record ​

Endpoint: PUT /api/v1/admin/scraper-price/records/:id

All fields are optional. Only provided fields will be updated. Validation rules (location codes, date logic, price ordering) are re-checked after merging changes.

bash
curl -X PUT /api/v1/admin/scraper-price/records/01ARZ3NDEKTSV4RRFFQ69G5FAV \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "highestPricePerAdult": 300.0,
    "scraperSource": "scraper-v2"
  }'

Response: 200 OK — Updated record.

7. Delete Price Record ​

Endpoint: DELETE /api/v1/admin/scraper-price/records/:id

Hard deletes the record from the database.

bash
curl -X DELETE /api/v1/admin/scraper-price/records/01ARZ3NDEKTSV4RRFFQ69G5FAV \
  -H "Authorization: Bearer <token>"

Response: 200 OK

json
{
  "success": true
}

Database Schema ​

Price records are stored in the ScraperPriceRecord table with the following indexes:

IndexFieldsPurpose
Primary KeyidUnique record identification
Route + Dateorigin, destination, departureDateFast lookups by route and date
Trip Type + ClasstripType, tripClassFilter by trip type and cabin
Scraped AtscrapedAtSort/filter by collection time
Created AtcreatedAtSort/filter by ingestion time

Error Responses ​

400 Bad Request ​

Returned when validation fails:

json
{
  "statusCode": 400,
  "message": "Invalid origin code: INVALID. No matching location found.",
  "error": "Bad Request"
}

401 Unauthorized ​

Returned when API key is missing or invalid (scraper endpoint), or JWT token is missing/invalid (admin endpoints):

json
{
  "statusCode": 401,
  "message": "Unauthorized",
  "error": "Unauthorized"
}

403 Forbidden ​

Returned when a non-admin user tries to access admin endpoints:

json
{
  "statusCode": 403,
  "message": "Forbidden resource",
  "error": "Forbidden"
}

404 Not Found ​

Returned when a record ID does not exist (admin GET/PUT/DELETE):

json
{
  "statusCode": 404,
  "message": "Scraper price record with id <id> not found",
  "error": "Not Found"
}

429 Too Many Requests ​

Returned when rate limit (100 req/min) is exceeded.
