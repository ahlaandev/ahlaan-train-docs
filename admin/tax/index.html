Tax Management Guide ​

This guide explains how administrators can configure VAT/tax rules for booking pricing.

Quick Overview ​

FeatureDescription
PurposeConfigure VAT/tax rules applied to booking pricing
Applied ToB2B and B2C booking calculations
Tax TypesPercentage-based (e.g., 11% VAT) or Fixed amount
FlexibilitySupport for organization-specific exemptions, route-specific taxes

How Tax Rules Work ​

Tax Calculation Flow ​

┌─────────────────────────────────────────────────────────────────┐
│                    TAX CALCULATION FLOW                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  1. Booking price is calculated (base + markups)                │
│                        ↓                                         │
│  2. System searches for applicable tax rules:                   │
│     ├─ Filter by target (ALL/B2B/B2C/ORGANIZATION)              │
│     ├─ Filter by route (origin/destination match)                │
│     ├─ Filter by date range (startDate/endDate)                  │
│     └─ Sort by priority (highest priority wins)                 │
│                        ↓                                         │
│  3. Calculate tax based on taxBasis:                            │
│                                                                  │
│     BASE_PRICE:      Tax on base ticket price only             │
│     FINAL_AMOUNT:    Tax on final amount (fare + markup + fees) │
│                        ↓                                         │
│  4. Add tax amount to final booking price                       │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Tax Rule Selection Priority ​

When multiple rules match, only ONE rule is applied based on:

  1. Priority (higher number = applied first)
  2. Most specific match (organization-specific > user-type-specific > ALL)
Priority Example:
  - Priority 100: "B2B Tax Exempt" (applies to specific organization)
  - Priority 50:  "Saudi VAT 11%" (applies to ALL)

  → B2B organization gets exemption (priority 100)
  → Regular B2C customers get 11% VAT (priority 50)

Tax Rule Fields ​

FieldTypeRequiredDescription
namestring✅Display name (max 255 chars)
descriptionstring-Detailed description (max 1000 chars)
targetenum✅Who this applies to: ALL, B2B, B2C, ORGANIZATION
organizationIdstring⚠️Required if target is ORGANIZATION
taxTypeenum✅PERCENTAGE or FIXED
taxRatenumber✅Tax rate (0-100 for PERCENTAGE)
taxCodestring-Code for reporting (e.g., VAT-11)
taxBasisenum✅What to calculate tax on
originstring-Route origin code (max 10 chars)
destinationstring-Route destination code (max 10 chars)
startDateISO date-Valid from date
endDateISO date-Valid until date
prioritynumber✅Higher = applied first (0-999999)
isActiveboolean✅Enable/disable this rule

Tax Type Options ​

ValueDescriptionExample
PERCENTAGEPercentage of price11 = 11% VAT
FIXEDFixed amount15000 = IDR 15,000 flat fee

Tax Basis Options ​

ValueDescriptionUse Case
BASE_PRICETax on base ticket price onlyBefore any markups
FINAL_AMOUNTTax on final amount (fare + markup + fees)After all markups (recommended, ensures B2B/B2C consistency)

Target Options ​

ValueDescriptionExample
ALLApplies to all bookingsStandard VAT rate
B2BB2B agents onlyB2B-specific tax rate
B2CRegular customers onlyB2C tax rate
ORGANIZATIONSpecific organizationTax exemption for org

Base URL ​

All tax management endpoints use:

/api/v1

All tax endpoints require:

  • JWT Token in Authorization header
  • ADMIN role in user account

Authorization: Bearer <your-admin-jwt-token>

Endpoints ​

1. Create Tax Rule ​

Endpoint: POST /admin/tax/rules

Create a new tax rule.

Request Body:

json
{
  "name": "VAT 11%",
  "description": "Standard VAT rate for all bookings",
  "target": "ALL",
  "taxType": "PERCENTAGE",
  "taxRate": 11,
  "taxCode": "VAT-11",
  "taxBasis": "FINAL_AMOUNT",
  "priority": 100,
  "isActive": true
}

Response: 201 Created

json
{
  "id": "019df123-4567-89ab-cdef-0123456789ab",
  "name": "VAT 11%",
  "description": "Standard VAT rate for all bookings",
  "target": "ALL",
  "organizationId": null,
  "taxType": "PERCENTAGE",
  "taxRate": 11.00,
  "taxCode": "VAT-11",
  "taxBasis": "FINAL_AMOUNT",
  "origin": null,
  "destination": null,
  "startDate": null,
  "endDate": null,
  "priority": 100,
  "isActive": true,
  "createdBy": "admin-123",
  "createdAt": "2026-01-28T10:00:00Z",
  "updatedAt": "2026-01-28T10:00:00Z"
}

2. List All Tax Rules ​

Endpoint: GET /admin/tax/rules

Get all tax rules with optional filtering.

Query Parameters:

ParameterTypeDescription
targetenumFilter by target type
organizationIdstringFilter by organization
originstringFilter by route origin
destinationstringFilter by route destination
isActivebooleanFilter by active status
pagenumberPage number (default: 1)
limitnumberItems per page (default: 20)

Examples:

bash
# Get all active tax rules
GET /admin/tax/rules?isActive=true

# Get B2B-specific rules
GET /admin/tax/rules?target=B2B

# Get route-specific rules
GET /admin/tax/rules?origin=DMX&destination=MKX

Response: 200 OK

json
{
  "data": [
    {
      "id": "tax-123",
      "name": "VAT 11%",
      "target": "ALL",
      "taxType": "PERCENTAGE",
      "taxRate": 11.00,
      "taxCode": "VAT-11",
      "taxBasis": "FINAL_AMOUNT",
      "isActive": true,
      "priority": 100
    }
  ],
  "meta": {
    "total": 1,
    "page": 1,
    "limit": 20,
    "totalPages": 1
  }
}

4. Update Tax Rule ​

Endpoint: PUT /admin/tax/rules/:id

Update an existing tax rule.

Request Body: (all fields optional)

json
{
  "name": "Updated VAT 11%",
  "taxRate": 12,
  "isActive": false
}

Response: 200 OK

json
{
  "id": "tax-123",
  "name": "Updated VAT 11%",
  "taxRate": 12.00,
  "isActive": false,
  "updatedAt": "2026-01-28T11:00:00Z"
}

5. Deactivate Tax Rule ​

Endpoint: DELETE /admin/tax/rules/:id

Soft delete by setting isActive to false.

Response: 200 OK

json
{
  "success": true
}

Common Workflows ​

Workflow 1: Create Standard VAT Rule ​

Scenario: Apply 11% VAT to all bookings

bash
curl -X POST /api/v1/admin/tax/rules \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "VAT 11%",
    "description": "Standard VAT rate for all bookings",
    "target": "ALL",
    "taxType": "PERCENTAGE",
    "taxRate": 11,
    "taxCode": "VAT-11",
    "taxBasis": "FINAL_AMOUNT",
    "priority": 100,
    "isActive": true
  }'

Workflow 2: Create Tax Exemption for B2B Organization ​

Scenario: Specific B2B organization is tax-exempt

bash
curl -X POST /api/v1/admin/tax/rules \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "B2B Tax Exempt - Agency ABC",
    "description": "Tax exemption for Agency ABC per MoU",
    "target": "ORGANIZATION",
    "organizationId": "org-abc-123",
    "taxType": "PERCENTAGE",
    "taxRate": 0,
    "taxCode": "TAX-FREE",
    "taxBasis": "FINAL_AMOUNT",
    "priority": 200,
    "isActive": true
  }'

Why priority 200? Higher than standard VAT (100), so it takes precedence.

Workflow 3: Route-Specific Tax ​

Scenario: Different tax for international routes

bash
curl -X POST /api/v1/admin/tax/rules \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "International Route Tax",
    "description": "Additional tax for international routes",

    "taxType": "PERCENTAGE",
    "taxRate": 5,
    "taxCode": "INT-TAX",
    "taxBasis": "FINAL_AMOUNT",
    "origin": "DMX",
    "destination": "JED",
    "priority": 150,
    "isActive": true
  }'

Tax Calculation Examples ​

Example 1: Standard VAT (FINAL_AMOUNT) ​

Base Price: 100,000 IDR
B2B Markup: 5,000 IDR
Markup 2: 2,000 IDR
─────────────────────
Subtotal: 107,000 IDR

Tax (11% on FINAL_AMOUNT): 107,000 × 0.11 = 11,770 IDR
─────────────────────
Final Price: 118,770 IDR

Example 2: VAT with B2B Exemption ​

Base Price: 100,000 IDR
B2B Markup: 5,000 IDR
─────────────────────
Subtotal: 105,000 IDR

Tax (0% - organization exempt): 0 IDR
─────────────────────
Final Price: 105,000 IDR
