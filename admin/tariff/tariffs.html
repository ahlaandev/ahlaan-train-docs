Managing Tariffs ​

This guide explains how to manage route-based tariff pricing for B2B group bookings.

Overview ​

Tariffs define fixed prices for specific routes, trip classes, and trip types. When B2B customers search for trains (11+ passengers), the system compares HHR prices against your configured tariffs and returns the better option.

Tariff Structure ​

FieldDescriptionExample
idAuto-generated UUIDtariff-abc123
originIdOrigin location UUID (must exist in locations)loc-xyz789
destinationIdDestination location UUID (must exist in locations)loc-abc456
originCodeOrigin station code (from location)DMX
originNameOrigin station name (from location)Madinah
destinationCodeDestination station code (from location)MKX
destinationNameDestination station name (from location)Makkah
tripClassCabin classECONOMY or BUSINESS
tripTypeTrip directionONE_WAY or ROUND_TRIP
pricePrice per adult (SAR, max 2 decimals)150.00
isActiveWhether tariff is used in B2B pricingtrue

Unique Constraint ​

Each combination of (originId, destinationId, tripClass, tripType) must be unique. You cannot have two active tariffs for the same route/class/type.

Endpoints ​

EndpointMethodDescription
/admin/v1/tariffsPOSTCreate new tariff
/admin/v1/tariffsGETList all tariffs with filtering
/admin/v1/tariffs/:idGETGet tariff by ID
/admin/v1/tariffs/:idPUTUpdate tariff
/admin/v1/tariffs/:idDELETESoft delete (deactivate) tariff

How Tariffs Are Used in B2B Pricing ​

When a B2B customer searches for trains (11+ passengers), the system:

  1. Fetches all active tariffs matching the search criteria
  2. Compares HHR price vs Tariff price for each matching tariff
  3. Returns the better price to the customer

Pricing Logic ​

if HHR price >= Tariff price:
    Final Price = Tariff price + B2B markup
    pricingSource = "TARIFF"

else if HHR price < Tariff price:
    Final Price = HHR price - B2B markup (discount)
    pricingSource = "HHR_DISCOUNTED"

else (no tariff exists):
    Final Price = HHR price + B2B markup
    pricingSource = "HHR_STANDARD"

Example ​

Scenario: B2B customer searches for 15 adults, DMX → MKX, Economy, One-way

SourcePrice per AdultTotal for 15 Adults
HHR200 SAR3,000 SAR
Tariff150 SAR2,250 SAR

Result:

  • Tariff is cheaper, so system uses: 150 + 50 (markup) = 200 SAR/adult
  • pricingSource = "TARIFF"
  • Customer saves: 3,000 - 3,000 = 0 SAR (after markup)

TypeScript - Create Tariff ​

typescript
interface CreateTariffDto {
  originId: string;
  destinationId: string;
  tripClass: 'ECONOMY' | 'BUSINESS';
  tripType: 'ONE_WAY' | 'ROUND_TRIP';
  price: number;
  isActive?: boolean;
}

interface Tariff {
  id: string;
  originId: string;
  originCode: string;
  originName: string;
  destinationId: string;
  destinationCode: string;
  destinationName: string;
  tripClass: 'ECONOMY' | 'BUSINESS';
  tripType: 'ONE_WAY' | 'ROUND_TRIP';
  price: number;
  isActive: boolean;
  createdBy?: string;
  updatedBy?: string;
  createdAt: string;
  updatedAt: string;
}

async function createTariff(
  data: CreateTariffDto,
  adminToken: string
): Promise<Tariff> {
  const response = await fetch('/api/v1/admin/tariffs', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${adminToken}`,
    },
    body: JSON.stringify(data),
  });

  if (!response.ok) {
    const error = await response.json();
    throw new Error(error.message || 'Failed to create tariff');
  }

  return await response.json();
}

// Example: Create Madinah to Makkah Economy tariff
const tariff = await createTariff({
  originId: 'loc-abc123',
  destinationId: 'loc-def456',
  tripClass: 'ECONOMY',
  tripType: 'ONE_WAY',
  price: 150.00,
  isActive: true,
}, 'your-admin-token');

console.log(`Created tariff: ${tariff.id} - ${tariff.originCode} → ${tariff.destinationCode}`);

Python - List and Filter Tariffs ​

python
import requests

def list_tariffs(
    admin_token: str,
    origin_id: str = None,
    trip_class: str = None,
    is_active: bool = True
):
    """List tariffs with optional filtering."""
    url = "https://api.example.com/api/v1/admin/tariffs"
    headers = {"Authorization": f"Bearer {admin_token}"}
    params = {
        "isActive": is_active,
        "page": 1,
        "limit": 100
    }

    if origin_id:
        params["originId"] = origin_id
    if trip_class:
        params["tripClass"] = trip_class

    response = requests.get(url, headers=headers, params=params)
    response.raise_for_status()

    data = response.json()

    for tariff in data['data']:
        print(f"{tariff['originCode']} → {tariff['destinationCode']} "
              f"({tariff['tripClass']}): {tariff['price']} SAR")

    return data

# Example: Get all active Economy tariffs
tariffs = list_tariffs("your-admin-token", trip_class="ECONOMY")

Best Practices ​

1. Complete Route Coverage ​

Create tariffs for all possible route combinations to ensure competitive pricing:

OriginDestinationClassType
DMXMKXECONOMYONE_WAY
DMXMKXBUSINESSONE_WAY
DMXMKXECONOMYROUND_TRIP
DMXMKXBUSINESSROUND_TRIP
............

Total: 4 locations × 4 locations × 2 classes × 2 types = 64 possible tariffs

2. Price Competitively ​

Set tariff prices based on:

  • MoU/negotiated rates with partners
  • Volume discounts for large groups
  • Seasonal demand patterns
  • Competitive analysis

3. Use Active Status Wisely ​

  • Activate (isActive: true): Tariff is used in B2B pricing
  • Deactivate (isActive: false): Temporarily disable without deleting

4. Update Prices Responsibly ​

  • Price changes apply immediately to all new B2B searches
  • Existing bookings are not affected
  • Consider price change frequency to avoid customer confusion

5. Audit Trail ​

The system tracks:

  • createdBy: User who created the tariff
  • updatedBy: User who last updated the tariff
  • createdAt / updatedAt: Timestamps

Troubleshooting ​

Issue: Cannot create tariff - "Location does not exist" ​

Cause: One or both location IDs are invalid.

Solution:

  1. List all locations: GET /admin/v1/tariffs/locations
  2. Use valid location UUIDs from the response

Issue: Cannot create tariff - "Tariff already exists" ​

Cause: A tariff with the same (originId, destinationId, tripClass, tripType) already exists.

Solution:

  1. Update the existing tariff instead of creating a duplicate
  2. Or deactivate the existing tariff first

Issue: Tariff not appearing in B2B search ​

Possible causes:

  1. isActive is false - Set to true
  2. Locations are not active - Check locations endpoint
  3. No B2B user authentication - B2B pricing only applies to authenticated B2B users
  4. Search criteria doesn't match - Verify route, class, and type match exactly

Issue: Wrong price in B2B search ​

Check:

  1. Verify tariff price is correct
  2. Verify pricing config percentages are correct
  3. Check HHR price at the time of search (real-time)

Next Steps ​
