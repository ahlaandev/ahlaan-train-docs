Tariff Management Guide ​

This guide explains how administrators can manage tariff pricing for B2B group bookings (11+ passengers).

Quick Overview ​

FeatureDescription
PurposeConfigure fixed pricing for B2B group train bookings
Used ByB2B search endpoint (11+ passengers)
ComponentsLocations, Tariffs, Pricing Configuration

How Tariffs Work ​

The B2B Pricing Flow ​

┌─────────────────────────────────────────────────────────────────┐
│                    B2B PRICING COMPARISON FLOW                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  1. B2B user searches for trains (11+ passengers)                │
│                        ↓                                         │
│  2. System fetches BOTH prices:                                  │
│     ├─ HHR-api price (real-time)                                 │
│     └─ Tariff price (from your configured tariffs)               │
│                        ↓                                         │
│  3. PRICE COMPARISON:                                            │
│                                                                  │
│     IF HHR price >= Tariff price:                                │
│       → Use Tariff price + B2B markup                            │
│       → pricingSource = "TARIFF"                                 │
│                                                                  │
│     ELSE IF HHR price < Tariff price:                            │
│       → Use HHR price - B2B markup (discount)                    │
│       → pricingSource = "HHR_DISCOUNTED"                         │
│                                                                  │
│     ELSE (no tariff exists):                                     │
│       → Use HHR price + B2B markup                               │
│       → pricingSource = "HHR_STANDARD"                           │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

Required Setup Checklist ​

Before tariffs work for B2B searches, complete these steps in order:

  • [ ] Step 1: Create all HHR station locations (DMX, MKX, JXD, KCX)
  • [ ] Step 2: Create tariffs for each route/class/type combination
  • [ ] Step 3: Configure pricing percentages (child/infant)
  • [ ] Step 4: Test B2B search to verify tariffs are applied

Common Workflows ​

Workflow 1: Add New Tariff Route ​

Scenario: Add pricing for Madinah → Makkah, Economy, One-way

  1. Go to Locations Guide and verify both locations exist
  2. Go to Tariffs Guide and create a new tariff:
    json
    {
  "originId": "<location-id-dmx>",
  "destinationId": "<location-id-mkx>",
  "tripClass": "ECONOMY",
  "tripType": "ONE_WAY",
  "price": 150.00,
  "isActive": true
}
  3. Verify tariff appears in B2B search results

Workflow 2: Update Existing Tariff Price ​

  1. Get list of tariffs: GET /admin/v1/tariffs
  2. Find the tariff ID for the route you want to update
  3. Update the tariff: PUT /admin/v1/tariffs/{id}
  4. New price applies immediately to all B2B searches

Workflow 3: Change Child Pricing Percentage ​

  1. Go to Pricing Config Guide
  2. Update configuration: PUT /admin/v1/tariff-pricing-config
  3. New percentage applies to all B2B calculations immediately

Base URL ​

Authentication ​

All tariff management endpoints require:

  • JWT Token in Authorization header
  • ADMIN role in user account
