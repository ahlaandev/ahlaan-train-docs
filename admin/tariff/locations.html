Managing Locations ​

This guide explains how to manage HHR station locations for the tariff system.

Overview ​

Locations represent HHR train stations. You must create locations before you can create tariffs, as tariffs reference locations by ID.

Location Structure ​

FieldDescriptionExample
idAuto-generated UUIDloc-abc123
codeUnique station code (max 10 chars)DMX, MKX
nameHuman-readable station name (max 100 chars)Madinah
isActiveWhether location is available for tariffstrue

Endpoints ​

EndpointMethodDescription
/admin/v1/tariffs/locationsPOSTCreate new location
/admin/v1/tariffs/locationsGETList all locations
/admin/v1/tariffs/locations/:idGETGet location by ID
/admin/v1/tariffs/locations/:idPUTUpdate location
/admin/v1/tariffs/locations/:idDELETESoft delete (deactivate) location

Create Location ​

Create a new HHR station location.

http
POST /admin/v1/tariffs/locations
Authorization: Bearer <token>
Content-Type: application/json

Request Body ​

json
{
  "code": "DMX",
  "name": "Madinah",
  "isActive": true
}
FieldTypeRequiredConstraints
codestringYesMax 10 characters, unique, no HTML
namestringYesMax 100 characters, no HTML
isActivebooleanNoDefault: true

Response (201 Created) ​

json
{
  "id": "loc-abc123",
  "code": "DMX",
  "name": "Madinah",
  "isActive": true,
  "createdAt": "2026-01-27T10:00:00Z",
  "updatedAt": "2026-01-27T10:00:00Z"
}

Response (400 Bad Request) ​

json
{
  "statusCode": 400,
  "message": [
    "Location code cannot contain HTML tags or scripts",
    "Location code must not exceed 10 characters"
  ],
  "error": "Bad Request"
}

Response (409 Conflict) ​

json
{
  "statusCode": 409,
  "message": "Location with code 'DMX' already exists",
  "error": "Conflict"
}

List Locations ​

Get all locations with optional filtering.

http
GET /admin/v1/tariffs/locations?isActive=true&page=1&limit=20
Authorization: Bearer <token>

Query Parameters ​

ParameterTypeDefaultDescription
codestring-Filter by location code
isActiveboolean-Filter by active status
pagenumber1Page number
limitnumber20Items per page (max 100)

Response (200 OK) ​

json
{
  "data": [
    {
      "id": "loc-abc123",
      "code": "DMX",
      "name": "Madinah",
      "isActive": true,
      "createdAt": "2026-01-27T10:00:00Z",
      "updatedAt": "2026-01-27T10:00:00Z"
    },
    {
      "id": "loc-def456",
      "code": "MKX",
      "name": "Makkah",
      "isActive": true,
      "createdAt": "2026-01-27T10:00:00Z",
      "updatedAt": "2026-01-27T10:00:00Z"
    }
  ],
  "meta": {
    "total": 2,
    "page": 1,
    "limit": 20,
    "totalPages": 1
  }
}

Note: Results are ordered by location code in ascending order (A-Z).

http

Update Location ​

Update an existing location.

http
PUT /admin/v1/tariffs/locations/loc-abc123
Authorization: Bearer <token>
Content-Type: application/json

Request Body ​

All fields are optional.

json
{
  "code": "DMX",
  "name": "Madinah Station",
  "isActive": false
}

Response (200 OK) ​

json
{
  "id": "loc-abc123",
  "code": "DMX",
  "name": "Madinah Station",
  "isActive": false,
  "createdAt": "2026-01-27T10:00:00Z",
  "updatedAt": "2026-01-27T11:00:00Z"
}

Delete Location ​

Soft delete a location by setting isActive to false.

Important: You cannot delete a location that has active tariffs referencing it.

http
DELETE /admin/v1/tariffs/locations/loc-abc123
Authorization: Bearer <token>

Response (200 OK) ​

json
{
  "success": true
}

Response (400 Bad Request) - Has Active Tariffs ​

json
{
  "statusCode": 400,
  "message": "Cannot delete location with active tariffs. Please deactivate tariffs first.",
  "error": "Bad Request"
}

JavaScript/TypeScript - Create Location ​

typescript
interface CreateLocationDto {
  code: string;
  name: string;
  isActive?: boolean;
}

interface Location {
  id: string;
  code: string;
  name: string;
  isActive: boolean;
  createdAt: string;
  updatedAt: string;
}

async function createLocation(
  data: CreateLocationDto,
  adminToken: string
): Promise<Location> {
  const response = await fetch('/api/v1/admin/tariffs/locations', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${adminToken}`,
    },
    body: JSON.stringify(data),
  });

  if (!response.ok) {
    const error = await response.json();
    throw new Error(error.message || 'Failed to create location');
  }

  return await response.json();
}

// Example: Create Madinah location
const madinah = await createLocation({
  code: 'DMX',
  name: 'Madinah',
  isActive: true,
}, 'your-admin-token');

console.log(`Created location: ${madinah.id} (${madinah.code})`);

Python - List Locations ​

python
import requests

def list_locations(admin_token: str, is_active: bool = True):
    """List all locations with optional filtering."""
    url = "https://api.example.com/api/v1/admin/tariffs/locations"
    headers = {
        "Authorization": f"Bearer {admin_token}"
    }
    params = {
        "isActive": is_active,
        "page": 1,
        "limit": 20
    }

    response = requests.get(url, headers=headers, params=params)
    response.raise_for_status()

    data = response.json()

    for location in data['data']:
        print(f"{location['code']}: {location['name']}")

    return data

# Example: Get all active locations
locations = list_locations("your-admin-token", is_active=True)

Best Practices ​

1. Use Standard HHR Codes ​

Always use the official HHR station codes:

Official CodeStation Name
DMXMadinah
MKXMakkah
JXDAl-Sulimaniyah (Jeddah)
KCXKing Abdullah Economic City

2. Create All Locations First ​

Before creating tariffs, ensure all 4 HHR locations exist:

bash
# Verify all locations exist
GET /admin/v1/tariffs/locations

# Expected: 4 active locations

3. Don't Delete Active Locations ​

If you need to remove a location from use:

  1. First, deactivate all tariffs referencing that location
  2. Then, deactivate (delete) the location

4. Naming Consistency ​

Use full station names for clarity:

  • ✅ "Madinah"
  • ✅ "Al-Sulimaniyah (Jeddah)"
  • ❌ "Med" (too vague)
  • ❌ "Jeddah" (should include station name)

Troubleshooting ​

Issue: Cannot create location with duplicate code ​

Error: Location with code 'DMX' already exists

Solution: Each location code must be unique. If you need to change the name, update the existing location instead of creating a new one.

Issue: Cannot delete location ​

Error: Cannot delete location with active tariffs

Solution: First deactivate all tariffs that reference this location, then delete the location.

Issue: Location not appearing in tariff options ​

Cause: Location has isActive: false

Solution: Update the location to set isActive: true
