Admin - Custom Booking Manifests ​

This guide covers the admin endpoints for managing manifest files on custom bookings. Admins can upload, list, download, and delete manifests for any custom booking regardless of ownership.

Quick Overview ​

FeatureDescription
UploadPOST /api/v1/admin/custom-booking/:bookingId/manifests
ListGET /api/v1/admin/custom-booking/:bookingId/manifests
DownloadGET /api/v1/admin/custom-booking/:bookingId/manifests/:fileId/download
Presigned URLGET /api/v1/admin/custom-booking/:bookingId/manifests/:fileId/url
DeleteDELETE /api/v1/admin/custom-booking/:bookingId/manifests/:fileId
AccessAdmin role (ADMIN) required

Authentication & Authorization ​

All admin manifest endpoints require:

  1. JWT Authentication — Valid Bearer token
  2. Admin Role — User must have ADMIN role
http
Authorization: Bearer <admin-jwt-token>

Unauthorized or non-admin users receive 403 Forbidden.

Base URL ​

/api/v1/admin

1. Upload Manifest ​

Upload a file as a manifest for any custom booking.

http
POST /admin/custom-booking/:bookingId/manifests
Content-Type: multipart/form-data
Authorization: Bearer <admin-token>

cURL ​

bash
curl -X POST /api/v1/admin/custom-booking/booking-123/manifests \
  -H "Authorization: Bearer <admin-token>" \
  -F "file=@passenger-manifest.pdf"

Response (201) ​

json
{
  "id": "file-uuid-1",
  "filename": "passenger-manifest.pdf",
  "mimeType": "application/pdf",
  "size": 2048,
  "visibility": "PRIVATE",
  "entityType": "custom_booking_manifest",
  "entityId": "booking-123",
  "uploadedAt": "2026-04-11T10:00:00.000Z",
  "createdAt": "2026-04-11T10:00:00.000Z"
}

2. List Manifests ​

List all manifest files for any custom booking.

http
GET /admin/custom-booking/:bookingId/manifests
Authorization: Bearer <admin-token>

cURL ​

bash
curl -X GET /api/v1/admin/custom-booking/booking-123/manifests \
  -H "Authorization: Bearer <admin-token>"

Response (200) ​

json
[
  {
    "id": "file-uuid-1",
    "filename": "passenger-manifest.pdf",
    "mimeType": "application/pdf",
    "size": 2048,
    "status": "UPLOADED",
    "entityType": "custom_booking_manifest",
    "entityId": "booking-123",
    "createdAt": "2026-04-11T10:00:00.000Z"
  }
]

3. Download Manifest ​

Download a specific manifest file as a binary attachment.

Status side effect: if the booking is currently in PAID, this download automatically transitions it to WAITING_FOR_TICKET. The transition is silently skipped for any other booking status. See the Custom Booking Management guide for the full state machine.

http
GET /admin/custom-booking/:bookingId/manifests/:fileId/download
Authorization: Bearer <admin-token>

cURL ​

bash
curl -X GET /api/v1/admin/custom-booking/booking-123/manifests/file-uuid-1/download \
  -H "Authorization: Bearer <admin-token>" \
  -o manifest.pdf

Response (200) ​

Returns the file as a binary response with headers:

Content-Type: application/pdf
Content-Disposition: attachment; filename="passenger-manifest.pdf"

4. Get Presigned URL ​

Get a temporary presigned download URL for a manifest file.

http
GET /admin/custom-booking/:bookingId/manifests/:fileId/url?expiresIn=3600
Authorization: Bearer <admin-token>

Query Parameters ​

ParameterTypeRequiredDefaultDescription
expiresInnumberNo3600URL expiration time in seconds

Response (200) ​

json
{
  "url": "https://r2.example.com/presigned-url?X-Amz-Expires=3600&..."
}

5. Delete Manifest ​

Soft-delete a manifest file from any booking.

http
DELETE /admin/custom-booking/:bookingId/manifests/:fileId
Authorization: Bearer <admin-token>

cURL ​

bash
curl -X DELETE /api/v1/admin/custom-booking/booking-123/manifests/file-uuid-1 \
  -H "Authorization: Bearer <admin-token>"

Response (200) ​

json
{
  "message": "Manifest file deleted"
}
