API Endpoints ​

Complete reference for WhatsApp management API endpoints.

Authentication ​

GET /login ​

Initiate QR code login flow.

How It Works:

  • If no device ID is configured: Uses GoWA legacy mode (no X-Device-Id header)
  • If device ID is configured: Sends X-Device-Id header with request

Response:

json
{
  "code": "SUCCESS",
  "message": "QR code generated successfully",
  "results": {
    "qr_link": "http://localhost:3000/statics/images/qrcode/scan-qr-abc123.png",
    "qr_duration": 30
  }
}

Already Logged In:

json
{
  "code": "ALREADY_LOGGED_IN",
  "message": "Already logged in - session is active"
}

Note: The device ID is sourced from the WHATSAPP_DEVICE_ID environment variable; it is not changed by login.

GET /login-with-code ​

Generate a pairing code for phone number login (alternative to QR code).

Query Parameters:

ParameterTypeRequiredDescription
phonestringYesPhone number for pairing (e.g., 628123456789)

Example:

bash
GET /admin/whatsapp/login-with-code?phone=628123456789

Response:

json
{
  "code": "SUCCESS",
  "message": "Pairing code generated",
  "results": {
    "pairing_code": "K241-9XYZ"
  }
}

Note: The device ID is sourced from the WHATSAPP_DEVICE_ID environment variable; it is not changed by pairing.

GET /status ​

Get the current connection and authentication status.

How It Works:

  • If device ID is configured (via WHATSAPP_DEVICE_ID): Sends X-Device-Id header with request
  • If no device ID is configured: Uses GoWA legacy mode (no X-Device-Id header)

Response (Before Login):

json
{
  "code": "SUCCESS",
  "message": "Connection status retrieved",
  "results": {
    "is_connected": false,
    "is_logged_in": false
  }
}

Response (After Login):

json
{
  "code": "SUCCESS",
  "message": "Connection status retrieved",
  "results": {
    "is_connected": true,
    "is_logged_in": true,
    "device_id": "628123456789@s.whatsapp.net"
  }
}

Fields:

FieldTypeDescription
is_connectedbooleanWhether the device is connected to GoWA service
is_logged_inbooleanWhether the device is logged into WhatsApp
device_idstringThe device ID (included when configured)

POST /logout ​

Logout from WhatsApp and clear the session.

Response:

json
{
  "code": "SUCCESS",
  "message": "Logged out successfully"
}

POST /reconnect ​

Attempt to reconnect to the WhatsApp service.

Response:

json
{
  "code": "SUCCESS",
  "message": "Reconnection initiated"
}

Device Configuration ​

GET /config/device-id ​

Get the current device ID configuration. This is read-only — the device ID is sourced from the WHATSAPP_DEVICE_ID environment variable and cannot be set or cleared via the API.

Response:

json
{
  "deviceId": "ahlaan-train",
  "source": "environment",
  "isConfigured": true
}

Fields:

FieldTypeDescription
deviceIdstringThe current device ID from WHATSAPP_DEVICE_ID
sourcestringAlways environment
isConfiguredbooleanWhether a device ID is configured

Sandbox - Send Messages ​

Sandbox endpoints for testing the WhatsApp integration. All are POST requests under the /admin/whatsapp/sandbox prefix and require the admin role.

EndpointDescription
POST /admin/whatsapp/sandbox/send-messageSend a text message
POST /admin/whatsapp/sandbox/send-imageSend an image
POST /admin/whatsapp/sandbox/send-fileSend a file
POST /admin/whatsapp/sandbox/send-videoSend a video
POST /admin/whatsapp/sandbox/send-audioSend an audio message

Example (send text message):

bash
curl -X POST http://localhost:3000/api/v1/admin/whatsapp/sandbox/send-message \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "phone": "628987654321",
    "message": "Hello from HHR API!"
  }'

Device ID Formats ​

No Device ID (Legacy Mode) ​

When WHATSAPP_DEVICE_ID is unset, the system uses GoWA's legacy mode:

  • No X-Device-Id header sent to GoWA
  • GoWA uses its default device for /app/* endpoints

Real Device ID (Phone Number) ​

Format: {phone_number}@s.whatsapp.net

Example: 628123456789@s.whatsapp.net

  • Phone Number: 10-15 digits, country code + number
  • Suffix: Must end with @s.whatsapp.net
  • Configured via: WHATSAPP_DEVICE_ID environment variable
  • Used: Sent as X-Device-Id header for all subsequent API calls

Device ID Source ​

The device ID is resolved directly from the WHATSAPP_DEVICE_ID environment variable. There is no database or cache layer — when the variable is unset, the service uses GoWA legacy mode (no X-Device-Id header).
