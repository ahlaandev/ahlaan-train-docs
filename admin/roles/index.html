Admin Roles & Permissions Guide ​

This guide explains how administrators can manage admin roles, permissions, and user assignments.

Quick Overview ​

FeatureDescription
PurposeManage admin roles and fine-grained permissions
AccessAdmin only
ScopeAll admin users and their permissions

Base URL ​

All roles endpoints use:

/api/v1

Authentication ​

All roles endpoints require:

  • JWT Token in Authorization header
  • ADMIN role in user account
http
Authorization: Bearer <your-admin-jwt-token>

Endpoints ​

1. Create Admin Role ​

Endpoint: POST /admin/roles

Create a new admin role with specific permissions.

Request Body:

json
{
  "name": "Finance Manager",
  "description": "Can manage invoices and payments",
  "permissions": [
    "invoice.create",
    "invoice.read",
    "invoice.update",
    "payment.create",
    "payment.read",
    "payment.refund",
    "wallet.read"
  ],
  "isActive": true
}

Response: 201 Created

json
{
  "id": "role-uuid",
  "name": "Finance Manager",
  "description": "Can manage invoices and payments",
  "permissions": [
    "invoice.create",
    "invoice.read",
    "invoice.update",
    "payment.create",
    "payment.read",
    "payment.refund",
    "wallet.read"
  ],
  "isActive": true,
  "createdAt": "2026-01-31T10:00:00Z"
}

2. List All Admin Roles ​

Endpoint: GET /admin/roles

Get all admin roles with optional filtering.

Query Parameters:

ParameterTypeDescription
isActivebooleanFilter by active status
pagenumberPage number (default: 1)
limitnumberItems per page (default: 20)

Example:

bash
GET /admin/roles?isActive=true

Response: 200 OK

json
{
  "data": [
    {
      "id": "role-uuid",
      "name": "Finance Manager",
      "description": "Can manage invoices and payments",
      "permissions": ["invoice.create", "payment.create"],
      "isActive": true,
      "userCount": 5,
      "createdAt": "2026-01-31T10:00:00Z"
    }
  ],
  "meta": {
    "total": 10,
    "page": 1,
    "limit": 20,
    "totalPages": 1
  }
}

4. Get Role by ID ​

Endpoint: GET /admin/roles/:id

Get details of a specific role.

Response: 200 OK

json
{
  "id": "role-uuid",
  "name": "Finance Manager",
  "description": "Can manage invoices and payments",
  "permissions": [
    "invoice.create",
    "invoice.read",
    "invoice.update",
    "payment.create",
    "payment.read",
    "payment.refund",
    "wallet.read"
  ],
  "isActive": true,
  "assignedUsers": [
    {
      "id": "user-uuid",
      "name": "John Admin",
      "email": "john@hhr.com"
    }
  ],
  "createdAt": "2026-01-31T10:00:00Z",
  "updatedAt": "2026-01-31T10:00:00Z"
}

5. Update Admin Role ​

Endpoint: PATCH /admin/roles/:id

Update an existing role.

Request Body: (all fields optional)

json
{
  "name": "Senior Finance Manager",
  "description": "Can manage all finance operations",
  "permissions": [
    "invoice.*",
    "payment.*",
    "wallet.*",
    "refund.*"
  ],
  "isActive": true
}

Response: 200 OK

json
{
  "id": "role-uuid",
  "name": "Senior Finance Manager",
  "description": "Can manage all finance operations",
  "permissions": ["invoice.*", "payment.*", "wallet.*", "refund.*"],
  "isActive": true,
  "updatedAt": "2026-01-31T11:00:00Z"
}

6. Deactivate Admin Role ​

Endpoint: DELETE /admin/roles/:id

Soft delete a role by setting isActive to false.

Response: 200 OK

json
{
  "success": true,
  "message": "Role deactivated successfully"
}

User Role Assignment ​

7. Assign Role to User ​

Endpoint: POST /admin/roles/users/:userId/roles

Assign a role to a user.

Request Body:

json
{
  "roleId": "role-uuid"
}

Response: 200 OK

json
{
  "userId": "user-uuid",
  "roleId": "role-uuid",
  "assignedAt": "2026-01-31T12:00:00Z",
  "assignedBy": "admin-uuid"
}

8. Revoke Role from User ​

Endpoint: DELETE /admin/roles/users/:userId/roles/:roleId

Remove a role assignment from a user.

Response: 200 OK

json
{
  "success": true,
  "message": "Role revoked successfully"
}

9. Get User Roles ​

Endpoint: GET /admin/roles/users/:userId/roles

Get all roles assigned to a user.

Response: 200 OK

json
{
  "userId": "user-uuid",
  "userName": "John Admin",
  "roles": [
    {
      "id": "role-uuid",
      "name": "Finance Manager",
      "description": "Can manage invoices and payments",
      "assignedAt": "2026-01-01T00:00:00Z"
    }
  ]
}

10. Get User Effective Permissions ​

Endpoint: GET /admin/roles/users/:userId/permissions

Get all effective permissions for a user (merged from all assigned roles).

Response: 200 OK

json
{
  "userId": "user-uuid",
  "permissions": [
    "invoice.create",
    "invoice.read",
    "invoice.update",
    "invoice.delete",
    "payment.create",
    "payment.read",
    "payment.refund",
    "wallet.read"
  ]
}

11. Get Current Admin Permissions ​

Endpoint: GET /admin/roles/users/me/permissions

Get the current logged-in admin's permissions.

Response: 200 OK

json
{
  "permissions": [
    "invoice.create",
    "invoice.read",
    "payment.create",
    "payment.read",
    "payment.refund"
  ]
}

Predefined Role Templates ​

Super Admin ​

Full system access with all permissions.

Permissions: *

Best for: System owners, CTO, technical founders

Finance Manager ​

Manage all finance operations including invoices, payments, refunds, and wallets.

Permissions:

  • invoice.*
  • payment.*
  • wallet.read
  • webhook.read

Best for: Finance team leads, accountants

Operations Manager ​

Manage bookings and provide customer support.

Permissions:

  • booking.read
  • booking.update
  • booking.cancel
  • user.read
  • user.update
  • wallet.read
  • invoice.read

Best for: Operations team leads, customer support managers

Support Agent ​

Read-only access for customer support.

Permissions:

  • booking.read
  • user.read
  • invoice.read
  • payment.read

Best for: Customer support agents

B2B Manager ​

Manage B2B applications and pricing.

Permissions:

  • b2b.*
  • pricing.read
  • pricing.create
  • pricing.update
  • tariff.read
  • organization.read

Best for: B2B sales managers, partnership managers

Permission Merging ​

When a user has multiple roles, permissions are merged:

User: John Admin
Roles: [Finance Manager, Support Agent]

Finance Manager permissions:
  - invoice.*
  - payment.*

Support Agent permissions:
  - booking.read
  - user.read

Effective permissions (union):
  - invoice.*
  - payment.*
  - booking.read
  - user.read

Need Help? ​

For questions or issues:

  1. Use predefined templates for common roles
  2. Assign minimum required permissions (principle of least privilege)
  3. Regularly review and audit role assignments
  4. Test new roles with a test user first
