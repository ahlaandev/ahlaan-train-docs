Bank Management Guide ​

This guide explains how administrators can manage Indonesian banks for wallet top-up bank transfer payments.

Quick Overview ​

FeatureDescription
PurposeConfigure supported Indonesian banks for wallet top-ups
AccessAdmin only
UsageBanks are displayed as options for bank transfer payments

Base URL ​

All bank management endpoints use:

/api/v1

Authentication ​

All bank endpoints require:

  • JWT Token in Authorization header
  • ADMIN role in user account
http
Authorization: Bearer <your-admin-jwt-token>

Endpoints ​

1. List All Banks ​

Endpoint: GET /admin/banks

Get all configured banks (active and inactive).

Query Parameters:

2. Get Public Bank List ​

Endpoint: GET /banks

Get list of active banks (used in frontend).

Authentication required

This endpoint requires a valid JWT (AuthGuard('jwt')). Calling it without a token returns 401 Unauthorized. It returns the same full { data, meta } admin row shape.

Response: 200 OK

3. Create Bank ​

Endpoint: POST /admin/banks

Add a new bank to the system.

Request Body:

json
{
  "code": "DIGI",
  "name": "Bank Digibyer",
  "swiftCode": "DIGIIDJA",
  "country": "ID",
  "logoUrl": "https://cdn.example.com/banks/digi.png",
  "isActive": true
}

Validation Rules:

FieldValidation
codeRequired, unique, uppercase, max 20 chars
nameRequired, max 255 chars
swiftCodeOptional, @Length(8, 11) + SWIFT/BIC format regex
countryOptional, ISO 3166-1 alpha-2 code (e.g., ID)
logoUrlOptional, URL

Response: 201 Created

json
{
  "id": "019df123-4567-89ab-cdef-0123456789ab",
  "code": "DIGI",
  "name": "Bank Digibyer",
  "swiftCode": "DIGIIDJA",
  "country": "ID",
  "logoUrl": "https://cdn.example.com/banks/digi.png",
  "isActive": true,
  "createdBy": "admin-uuid",
  "updatedBy": null,
  "createdAt": "2026-01-28T10:00:00Z",
  "updatedAt": "2026-01-28T10:00:00Z"
}

4. Update Bank ​

Endpoint: PUT /admin/banks/{id}

Update bank details by the bank's UUID id (code cannot be changed).

Request Body:

json
{
  "name": "Updated Bank Name",
  "swiftCode": "NEWSWIFT",
  "isActive": false
}

Response: 200 OK

json
{
  "id": "019df123-4567-89ab-cdef-0123456789ab",
  "code": "DIGI",
  "name": "Updated Bank Name",
  "swiftCode": "NEWSWIFT",
  "country": "ID",
  "logoUrl": null,
  "isActive": false,
  "createdBy": "admin-uuid",
  "updatedBy": "admin-uuid",
  "createdAt": "2026-01-28T10:00:00Z",
  "updatedAt": "2026-01-28T11:00:00Z"
}

5. Deactivate Bank ​

Endpoint: DELETE /admin/banks/{id}

Soft delete by setting isActive to false (by the bank's UUID id).

Response: 200 OK

json
{
  "success": true
}

Common Workflows ​

Workflow 1: Add New Bank ​

Scenario: Add a new Indonesian bank to the system

bash
curl -X POST /api/v1/admin/banks \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "code": "DANAMON",
    "name": "Bank Danamon",
    "swiftCode": "BDMMIDJA",
    "country": "ID",
    "isActive": true
  }'

Workflow 2: Temporarily Disable Bank ​

Scenario: Temporarily disable a bank for maintenance

bash
curl -X PUT /api/v1/admin/banks/019df123-4567-89ab-cdef-0123456789ab \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "isActive": false
  }'
