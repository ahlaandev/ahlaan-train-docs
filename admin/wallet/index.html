Wallet Management Guide ​

This guide explains how administrators can manage user wallets, transactions, and withdrawal requests.

Quick Overview ​

FeatureDescription
PurposeManage customer wallets and transactions
AccessAdmin only
ScopeAll USER and ORGANIZATION wallets

Base URL ​

All wallet management endpoints use:

/api/v1

Authentication ​

All wallet endpoints require:

  • JWT Token in Authorization header
  • ADMIN role in user account
http
Authorization: Bearer <your-admin-jwt-token>

Overview Endpoints ​

1. Get All Wallets ​

Endpoint: GET /admin/wallet/list

List all wallets with pagination, search, and filters.

Query Parameters:

ParameterTypeDescription
searchstringSearch by owner name, email, or org code
typeenumFilter: USER, ORGANIZATION
statusenumFilter: ACTIVE, SUSPENDED, CLOSED
minBalancenumberMinimum balance (SAR)
maxBalancenumberMaximum balance (SAR)
pagenumberPage number (default: 1)
limitnumberItems per page (default: 20)

Example:

bash
GET /admin/wallet/list?search=john&type=USER&status=ACTIVE

User Withdrawal Endpoints ​

Access Control

User withdrawal endpoints are B2B-only. Only users with ADMIN or B2B roles can access these endpoints. B2C users will receive 403 Forbidden.

Role Requirements

  • ADMIN - Can access all withdrawal endpoints
  • B2B - Can access all withdrawal endpoints for their organization
  • B2C - Not allowed - Will receive 403 Forbidden

Create Withdrawal Request ​

Endpoint: POST /v1/wallet/withdrawal

Request a withdrawal from your wallet. Funds will be held until admin approval.

Authentication: Bearer token (JWT)

Request Body:

json
{
  "amount": 2000.00,
  "bankDetailsId": "bank-details-uuid"
}

Response: 201 Created

json
{
  "id": "withdrawal-uuid",
  "walletId": "wallet-uuid",
  "amount": 2000.00,
  "currency": "SAR",
  "status": "PENDING",
  "bankDetails": {
    "bankName": "BCA",
    "accountNumber": "1234567890",
    "accountHolderName": "John Doe"
  },
  "requestedAt": "2026-02-04T10:00:00Z"
}

Error Responses:

StatusDescription
403 ForbiddenUser is B2C (withdrawal not allowed)
400 Bad RequestInsufficient balance or invalid bank details
