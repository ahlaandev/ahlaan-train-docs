HHR API Documentation ​

Welcome to the HHR API documentation. This site contains how-to guides and API reference for integrating with the Ahlaan Train booking system.

Quick Start ​

Base URL ​

/api/v1

API Response Format ​

All endpoints return JSON responses with consistent error handling:

json
{
  "statusCode": 400,
  "message": "Detailed error message",
  "error": "Bad Request"
}

Quick Example ​

B2C Search (1-10 passengers) ​

bash
curl -X POST /api/v1/ota/search \
  -H "Content-Type: application/json" \
  -d '{
    "origin": "DMX",
    "destination": "MKX",
    "departureDate": "2026-02-01",
    "tripType": "ONE_WAY",
    "passengerQuantities": {"adults": 2}
  }'

B2B Search (11+ passengers) ​

bash
curl -X POST /api/v1/ota/search \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{
    "origin": "DMX",
    "destination": "MKX",
    "departureDate": "2026-02-01",
    "tripType": "ONE_WAY",
    "passengerQuantities": {"adults": 15}
  }'
