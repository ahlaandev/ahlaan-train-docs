Train Availability Range ​

This guide explains how to retrieve train availability across multiple dates in a single request. Use this endpoint for building multi-date calendar views or price comparison features.

Quick Overview ​

FeatureEndpointAuth
Availability RangePOST /api/v1/ota/availability-rangeOptional

Booking Class Codes ​

This endpoint uses standard OTA booking class codes as defined in the OTA API Specification:

Class CodeDescription
CBusiness class
YEconomy class

Note: This endpoint returns seat availability with pricing. Use /ota/search for detailed fare options and booking.

Pricing Modes ​

The endpoint supports two pricing modes:

B2C Pricing (Default) ​

For individual customers (≤10 passengers). Uses standard HHR markup + tax calculation.

B2B Pricing ​

For business agents (>10 passengers). Uses tariff comparison pricing with percentage-based markup.

ModePassengersPricing Logic
B2C≤10HHR markup + tax
B2B>10Tariff comparison + B2B markup

To enable B2B pricing, set isB2B: true in the request body.

Use Cases ​

  1. Multi-date Calendar View - Show seat availability for the next 7 days at a glance
  2. Availability Check - Find which dates have seats available
  3. Trip Planning - Check availability for flexible travel dates

Note: This endpoint returns seat availability with pricing. Use /ota/search for detailed fare options and booking.

Base URL ​

/api/v1

Get Availability Range ​

Retrieve train availability for the next 7 days (today + 6 days) in a single request.

http
POST /ota/availability-range
Content-Type: application/json
Authorization: Bearer <token>  # Optional

Request Body ​

json
{
  "origin": "MKX",
  "destination": "DMX"
}

Request Parameters ​

ParameterTypeRequiredDescription
originstringYesOrigin station code (e.g., MKX)
destinationstringYesDestination station code (e.g., DMX)
isB2BbooleanNoEnable B2B pricing mode (default: false)

Note: The date range is automatically set to 7 days starting from today. You don't need to specify dates.

B2B Pricing ​

When isB2B: true is set, the endpoint uses B2B tariff comparison pricing for bookings with more than 10 passengers. The pricing logic compares HHR prices with internal tariff rates and applies the better rate with B2B markup.

Validation Rules ​

RuleDescription
Station CodesMust be valid station codes (e.g., MKX, DMX)

Cache Behavior ​

This endpoint uses Redis caching for improved performance:

PropertyValue
Cache TTL30 minutes (configurable via system config)
Cache Keytrain_availability:{origin}:{destination}:{date}:{pricingMode}
Pricing Mode:b2c for B2C, :b2b for B2B pricing
Cache Warm-upAutomatic every 30 minutes for all routes (B2C only)

Code Examples ​

TypeScript ​

typescript
interface AvailabilityRangeParams {
  origin: string;
  destination: string;
  isB2B?: boolean;
}

interface PricePerAdultCurrency {
  amount: number;
  originalAmount: number | null;
}

interface PricePerAdult {
  SAR: PricePerAdultCurrency;
  IDR: PricePerAdultCurrency;
}

interface Fare {
  classCode: string;
  className: string;
  seatsAvailable: number;
  pricePerAdult: PricePerAdult;
}

interface DateAvailability {
  date: string;
  day: string;
  status: 'available' | 'limited' | 'sold_out';
  fares: Fare[];
}

interface Trip {
  trainNumber: string;
  departureTime: string;
  arrivalTime: string;
  availability: DateAvailability[];
}

interface AvailabilityRangeResponse {
  scheduleMeta: {
    origin: { code: string; name: string };
    destination: { code: string; name: string };
    dateRange: { start: string; end: string };
  };
  trips: Trip[];
}

async function getAvailabilityRange(
  params: AvailabilityRangeParams,
  token?: string
): Promise<AvailabilityRangeResponse> {
  const headers: HeadersInit = {
    'Content-Type': 'application/json',
  };

  if (token) {
    headers['Authorization'] = `Bearer ${token}`;
  }

  const response = await fetch('/api/v1/ota/availability-range', {
    method: 'POST',
    headers,
    body: JSON.stringify(params),
  });

  if (!response.ok) {
    const error = await response.json();
    throw new Error(error.message || 'Failed to fetch availability');
  }

  return response.json();
}

// Usage example
async function checkWeekAvailability() {
  const result = await getAvailabilityRange({
    origin: 'MKX',
    destination: 'DMX',
  });

  // Find dates with best availability
  const availableDates: string[] = [];

  for (const trip of result.trips) {
    for (const day of trip.availability) {
      if (day.status === 'available' && !availableDates.includes(day.date)) {
        availableDates.push(day.date);
      }
    }
  }

  console.log(`Available dates: ${availableDates.join(', ')}`);
  return result;
}

React Component Example ​

tsx
import { useState, useEffect } from 'react';

interface DateCardProps {
  date: string;
  day: string;
  status: string;
  minSeats?: number;
  onClick?: () => void;
}

function DateCard({ date, day, status, minSeats, onClick }: DateCardProps) {
  const isAvailable = status === 'available';

  return (
    <button
      onClick={onClick}
      disabled={!isAvailable}
      style={{
        padding: '12px',
        border: '1px solid #ddd',
        borderRadius: '8px',
        backgroundColor: isAvailable ? '#fff' : '#f5f5f5',
        cursor: isAvailable ? 'pointer' : 'not-allowed',
        opacity: isAvailable ? 1 : 0.6,
      }}
    >
      <div style={{ fontWeight: 'bold' }}>{new Date(date).getDate()}</div>
      <div style={{ fontSize: '12px', color: '#666' }}>{day}</div>
      {isAvailable && minSeats !== undefined && (
        <div style={{ fontSize: '12px', color: '#22c55e' }}>
          {minSeats} seats available
        </div>
      )}
      {!isAvailable && (
        <div style={{ fontSize: '12px', color: '#999' }}>Sold out</div>
      )}
    </button>
  );
}

function AvailabilityCalendar({ origin, destination }: { origin: string; destination: string }) {
  const [trips, setTrips] = useState<Trip[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch('/api/v1/ota/availability-range', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        origin,
        destination,
      }),
    })
      .then(res => res.json())
      .then(data => {
        setTrips(data.trips);
        setLoading(false);
      });
  }, [origin, destination]);

  if (loading) return <div>Loading availability...</div>;

  // Aggregate availability by date across all trips
  const dateMap = new Map<string, { day: string; status: string; minSeats: number }>();

  for (const trip of trips) {
    for (const day of trip.availability) {
      const existing = dateMap.get(day.date);
      const dayMinSeats = day.fares.length > 0
        ? Math.min(...day.fares.map(f => f.seatsAvailable))
        : 0;

      if (!existing) {
        dateMap.set(day.date, {
          day: day.day,
          status: day.status,
          minSeats: dayMinSeats,
        });
      } else {
        // Update status if any trip has availability
        if (day.status === 'available' && existing.status !== 'available') {
          existing.status = 'available';
        }
        // Update min seats
        if (dayMinSeats > 0 && (existing.minSeats === 0 || dayMinSeats < existing.minSeats)) {
          existing.minSeats = dayMinSeats;
        }
      }
    }
  }

  return (
    <div style={{ display: 'grid', gridTemplateColumns: 'repeat(7, 1fr)', gap: '8px' }}>
      {Array.from(dateMap.entries()).map(([date, info]) => (
        <DateCard
          key={date}
          date={date}
          day={info.day}
          status={info.status}
          minSeats={info.minSeats === 0 ? undefined : info.minSeats}
        />
      ))}
    </div>
  );
}

bash
# Get availability for the next 7 days (B2C pricing)
curl -X POST /api/v1/ota/availability-range \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{
    "origin": "MKX",
    "destination": "DMX"
  }'

# Get availability with B2B pricing (>10 passengers)
curl -X POST /api/v1/ota/availability-range \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{
    "origin": "MKX",
    "destination": "DMX",
    "isB2B": true
  }'
