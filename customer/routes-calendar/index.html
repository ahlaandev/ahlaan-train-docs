Routes & Calendar ​

This guide explains how to retrieve available train routes and calendar availability data for building booking UIs.

Quick Overview ​

FeatureDescription
Routes EndpointGET /api/v1/ota/routes
Calendar EndpointGET /api/v1/ota/calendar-availability
AuthenticationNot required (public endpoints)
Use CaseBuild station selection and date picker UIs

Base URL ​

/api/v1

Available Stations ​

CodeStation Name
DMXMadinah

KCXKing Abdullah Economic City

Get Available Routes ​

Retrieve all available train routes between stations. Use this endpoint to populate route selection dropdowns in your booking UI.

http
GET /ota/routes

Request Format ​

Headers

Content-Type: application/json

Query Parameters

None required.

Response Format ​

The response is a top-level array, one entry per origin station. Each entry contains the origin station and the list of destination stations reachable from it.

json
[
  {
    "origin": {
      "code": "DMX",
      "name": "Madinah",
      "cityName": "Madinah",
      "cityCode": "DMX",
      "country": "SA"
    },
    "destinations": [
      {
        "code": "JED",
        "name": "King Abdulaziz International Airport",
        "cityName": "Jeddah",
        "cityCode": "JED",
        "country": "SA"
      },
      {
        "code": "JXD",
        "name": "Al-Sulimaniyah",
        "cityName": "Jeddah",
        "cityCode": "JXD",
        "country": "SA"
      },
      {
        "code": "MKX",
        "name": "Makkah",
        "cityName": "Makkah",
        "cityCode": "MKX",
        "country": "SA"
      }
    ]
  }
]

Response Fields ​

The response body is an array of origin entries. Each entry has:

FieldTypeDescription
originobjectOrigin station
destinationsarrayStations reachable from this origin

Each station object (origin and every item in destinations):

FieldTypeDescription
codestringStation code
namestringStation name
cityNamestringCity name
cityCodestringCity code
countrystringISO 3166-1 alpha-2 country code

NOTE: Routes are bidirectional. Each origin station lists every destination reachable from it.

Get Calendar Availability ​

Retrieve availability status for dates within a range. Use this endpoint to display calendar UI with visual indicators for available/unavailable dates.

http
GET /ota/calendar-availability

Request Format ​

Query Parameters

ParameterTypeRequiredDescription
startDatestringYesStart date (YYYY-MM-DD)
endDatestringYesEnd date (YYYY-MM-DD)
departureAirportstringYesOrigin station code (DMX, JXD, KCX, MKX)
arrivalAirportstringYesDestination station code
directbooleanNoFilter for direct flights only (default: true)

Request Example ​

bash
GET /api/v1/ota/calendar-availability?startDate=2026-02-01&endDate=2026-02-28&departureAirport=DMX&arrivalAirport=MKX&direct=true

Response Format ​

The response echoes the requested range and route, plus a flat dates array listing the date strings (YYYY-MM-DD) that have availability. There are no per-date prices, classes, or flight counts — a date is present in dates if and only if trains are available on it.

json
{
  "startDate": "2026-02-01",
  "endDate": "2026-02-28",
  "departureAirport": "DMX",
  "arrivalAirport": "MKX",
  "dates": [
    "2026-02-07",
    "2026-02-06",
    "2026-02-05",
    "2026-02-04",
    "2026-02-03",
    "2026-02-02",
    "2026-02-01"
  ]
}

Response Fields ​

FieldTypeDescription
startDatestringRequested range start (YYYY-MM-DD)
endDatestringRequested range end (YYYY-MM-DD)
departureAirportstringOrigin station code
arrivalAirportstringDestination station code
datesarrayDate strings (YYYY-MM-DD) that have availability for this route

Calendar UI Implementation Guide ​

Visual Indicators ​

The endpoint returns only the set of available date strings (dates). Build a lookup Set from dates and mark each calendar cell available/unavailable. To show prices per date, call the search endpoint for the selected date (see the Search Trains guide).

Availability Lookup Strategy ​

javascript
function buildAvailabilitySet(response) {
  return new Set(response.dates);
}

function getDateStyle(availableDates, date) {
  if (!availableDates.has(date)) {
    return { color: 'gray', disabled: true };
  }
  return { color: 'green', label: 'Available' };
}

Code Examples ​

JavaScript/TypeScript (fetch) ​

typescript
interface Station {
  code: string;
  name: string;
  cityName: string;
  cityCode: string;
  country: string;
}

interface RouteEntry {
  origin: Station;
  destinations: Station[];
}

// Response is a top-level array of route entries
type RoutesResponse = RouteEntry[];

// Get available routes
async function getRoutes(): Promise<RoutesResponse> {
  const response = await fetch('/api/v1/ota/routes', {
    method: 'GET',
    headers: { 'Content-Type': 'application/json' },
  });

  if (!response.ok) {
    throw new Error(`Failed to fetch routes: ${response.statusText}`);
  }

  return await response.json();
}

// Populate route dropdown
async function populateRouteDropdown() {
  const routes = await getRoutes();
  const select = document.getElementById('route-select');

  routes.forEach((entry) => {
    entry.destinations.forEach((dest) => {
      const option = document.createElement('option');
      option.value = `${entry.origin.code}-${dest.code}`;
      option.textContent = `${entry.origin.name} → ${dest.name}`;
      select.appendChild(option);
    });
  });
}

// Calendar availability types
interface CalendarAvailabilityParams {
  startDate: string;
  endDate: string;
  departureAirport: string;
  arrivalAirport: string;
  direct?: boolean;
}

interface CalendarResponse {
  startDate: string;
  endDate: string;
  departureAirport: string;
  arrivalAirport: string;
  dates: string[];
}

// Get calendar availability
async function getCalendarAvailability(
  params: CalendarAvailabilityParams,
): Promise<CalendarResponse> {
  const queryParams = new URLSearchParams({
    startDate: params.startDate,
    endDate: params.endDate,
    departureAirport: params.departureAirport,
    arrivalAirport: params.arrivalAirport,
    ...(params.direct !== undefined && { direct: String(params.direct) }),
  });

  const response = await fetch(
    `/api/v1/ota/calendar-availability?${queryParams}`,
    {
      method: 'GET',
      headers: { 'Content-Type': 'application/json' },
    },
  );

  if (!response.ok) {
    throw new Error(`Failed to fetch calendar: ${response.statusText}`);
  }

  return await response.json();
}

// Render calendar with availability
async function renderCalendar(
  startDate: string,
  endDate: string,
  departureAirport: string,
  arrivalAirport: string,
) {
  const data = await getCalendarAvailability({
    startDate,
    endDate,
    departureAirport,
    arrivalAirport,
    direct: true,
  });

  const availableDates = new Set(data.dates);
  const calendar = document.getElementById('calendar');
  calendar.innerHTML = '';

  availableDates.forEach((date) => {
    const dayElement = document.createElement('div');
    dayElement.className = 'calendar-day available';
    dayElement.innerHTML = `<span class="date">${new Date(date).getDate()}</span>`;
    calendar.appendChild(dayElement);
  });
}

Validation Rules ​

RuleDescription
Date RangeMaximum 365 days between startDate and endDate
Date FormatMust be valid ISO 8601 dates (YYYY-MM-DD)
Station CodesMust be valid codes (DMX, JXD, KCX, MKX)
Same StationDeparture and arrival must be different stations
Past DatesStart date cannot be in the past

Error Responses ​

400 Bad Request - Invalid Date Range ​

json
{
  "statusCode": 400,
  "message": ["Date range cannot exceed 365 days"],
  "error": "Bad Request"
}

Solution: Reduce the date range to 365 days or less.

400 Bad Request - Invalid Station Code ​

json
{
  "statusCode": 400,
  "message": ["Invalid station code: XYZ"],
  "error": "Bad Request"
}

Solution: Use valid station codes (DMX, JXD, KCX, MKX).

400 Bad Request - Same Origin and Destination ​

json
{
  "statusCode": 400,
  "message": ["Departure and arrival airports cannot be the same"],
  "error": "Bad Request"
}

Solution: Use different station codes for departure and arrival.

Use Cases ​

1. Building a Route Selector ​

javascript
// After fetching routes, create origin/destination selectors
const routes = await getRoutes();

// Get unique station codes (origins + destinations)
const stations = [...new Set(
  routes.flatMap(entry => [
    entry.origin.code,
    ...entry.destinations.map(d => d.code),
  ]),
)];

// Populate selectors
populateStationSelector('origin-select', stations);
populateStationSelector('destination-select', stations);

2. Date Picker with Availability ​

javascript
// When user selects a route, fetch calendar availability
async function onRouteChange(origin, destination) {
  const today = new Date();
  const nextMonth = new Date(today.getFullYear(), today.getMonth() + 1, 0);

  const availability = await getCalendarAvailability({
    startDate: formatDate(today),
    endDate: formatDate(nextMonth),
    departureAirport: origin,
    arrivalAirport: destination,
  });

  renderCalendarWithAvailability(availability);
}

3. Listing Available Dates ​

javascript
// Get the sorted list of available dates in range
function listAvailableDates(response) {
  return [...response.dates].sort();
}
