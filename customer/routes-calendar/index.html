Routes & Calendar ​

This guide explains how to retrieve available train routes and calendar availability data for building booking UIs.

Quick Overview ​

FeatureDescription
Routes EndpointGET /api/v1/routes
Calendar EndpointGET /api/v1/calendar-availability
AuthenticationNot required (public endpoints)
Use CaseBuild station selection and date picker UIs

Base URL ​

/api/v1

Get Available Routes ​

Retrieve all available train routes between stations. Use this endpoint to populate route selection dropdowns in your booking UI.

http
GET /routes

Request Format ​

Headers

Content-Type: application/json

Query Parameters

None required.

Response Format ​

Response Fields ​

FieldTypeDescription
routesarrayList of available routes
originstringOrigin station code
destinationstringDestination station code
originNamestringFull origin station name

distanceKmnumberDistance between stations in kilometers
durationMinutesnumberTypical journey duration in minutes

NOTE: Routes are bidirectional. Each route in the response represents travel in both directions.

Get Calendar Availability ​

Retrieve availability status for dates within a range. Use this endpoint to display calendar UI with visual indicators for available/unavailable dates.

http
GET /calendar-availability

Request Format ​

Query Parameters

ParameterTypeRequiredDescription
startDatestringYesStart date (YYYY-MM-DD)
endDatestringYesEnd date (YYYY-MM-DD)
departureAirportstringYesOrigin station code (DMX, JXD, KCX, MKX)
arrivalAirportstringYesDestination station code
directbooleanNoFilter for direct flights only (default: true)

bash

Response Fields ​

Metadata ​

FieldTypeDescription
routeobjectRoute information
dateRangeobjectRequested date range
directOnlybooleanWhether only direct flights were included

Availability Array ​

FieldTypeDescription
datestringDate in YYYY-MM-DD format
availablebooleanWhether trains are available on this date
flightsCountnumberNumber of available trains
minPriceobjectLowest price across all classes (SAR/IDR)
classesobjectAvailability by cabin class
reasonstringReason if not available

Classes Object ​

FieldTypeDescription
BUSINESSobjectBusiness class availability
ECONOMYobjectEconomy class availability

Each class contains:

  • available: boolean - Whether this class is available
  • minPrice: object - Minimum price for this class (SAR/IDR)
  • faresAvailable: array - Available fare types (SAVER, PROMO, STANDARD)

Price Display Strategy ​

javascript
function getDateStyle(availability) {
  if (!availability.available) {
    return { color: 'gray', disabled: true };
  }

  const price = availability.minPrice.SAR;

  if (price < 300) {
    return { color: 'green', label: `from SAR ${price}` };
  } else if (price < 500) {
    return { color: 'yellow', label: `from SAR ${price}` };
  } else {
    return { color: 'orange', label: `from SAR ${price}` };
  }
}

Code Examples ​

JavaScript/TypeScript (fetch) ​

typescript
interface Route {
  origin: string;
  destination: string;
  originName: string;
  destinationName: string;
  distanceKm: number;
  durationMinutes: number;
}

interface RoutesResponse {
  routes: Route[];
}

// Get available routes
async function getRoutes(): Promise<RoutesResponse> {
  const response = await fetch('/api/v1/routes', {
    method: 'GET',
    headers: { 'Content-Type': 'application/json' },
  });

  if (!response.ok) {
    throw new Error(`Failed to fetch routes: ${response.statusText}`);
  }

  return await response.json();
}

// Populate route dropdown
async function populateRouteDropdown() {
  const { routes } = await getRoutes();
  const select = document.getElementById('route-select');

  routes.forEach((route) => {
    const option = document.createElement('option');
    option.value = `${route.origin}-${route.destination}`;
    option.textContent = `${route.originName} → ${route.destinationName}`;
    select.appendChild(option);
  });
}

// Calendar availability types
interface CalendarAvailabilityParams {
  startDate: string;
  endDate: string;
  departureAirport: string;
  arrivalAirport: string;
  direct?: boolean;
}

interface ClassAvailability {
  available: boolean;
  minPrice: { SAR: number; IDR: number };
  faresAvailable: string[];
}

interface DateAvailability {
  date: string;
  available: boolean;
  flightsCount: number;
  minPrice: { SAR: number; IDR: number };
  classes: {
    BUSINESS: ClassAvailability;
    ECONOMY: ClassAvailability;
  };
  reason?: string;
}

interface CalendarResponse {
  metadata: {
    route: {
      departureAirport: string;
      arrivalAirport: string;
      departureName: string;
      arrivalName: string;
    };
    dateRange: { start: string; end: string };
    directOnly: boolean;
  };
  availability: DateAvailability[];
}

// Get calendar availability
async function getCalendarAvailability(
  params: CalendarAvailabilityParams,
): Promise<CalendarResponse> {
  const queryParams = new URLSearchParams({
    startDate: params.startDate,
    endDate: params.endDate,
    departureAirport: params.departureAirport,
    arrivalAirport: params.arrivalAirport,
    ...(params.direct !== undefined && { direct: String(params.direct) }),
  });

  const response = await fetch(
    `/api/v1/calendar-availability?${queryParams}`,
    {
      method: 'GET',
      headers: { 'Content-Type': 'application/json' },
    },
  );

  if (!response.ok) {
    throw new Error(`Failed to fetch calendar: ${response.statusText}`);
  }

  return await response.json();
}

// Render calendar with availability
async function renderCalendar(
  startDate: string,
  endDate: string,
  departureAirport: string,
  arrivalAirport: string,
) {
  const data = await getCalendarAvailability({
    startDate,
    endDate,
    departureAirport,
    arrivalAirport,
    direct: true,
  });

  const calendar = document.getElementById('calendar');
  calendar.innerHTML = '';

  data.availability.forEach((day) => {
    const dayElement = document.createElement('div');
    dayElement.className = 'calendar-day';

    if (day.available) {
      dayElement.classList.add('available');
      dayElement.innerHTML = `
        <span class="date">${new Date(day.date).getDate()}</span>
        <span class="price">from SAR ${day.minPrice.SAR}</span>
      `;
    } else {
      dayElement.classList.add('unavailable');
      dayElement.innerHTML = `<span class="date">${new Date(day.date).getDate()}</span>`;
    }

    calendar.appendChild(dayElement);
  });
}

Validation Rules ​

RuleDescription
Date RangeMaximum 365 days between startDate and endDate
Date FormatMust be valid ISO 8601 dates (YYYY-MM-DD)
Station CodesMust be valid codes (DMX, JXD, KCX, MKX)
Same StationDeparture and arrival must be different stations
Past DatesStart date cannot be in the past

Error Responses ​

400 Bad Request - Invalid Date Range ​

json
{
  "statusCode": 400,
  "message": ["Date range cannot exceed 365 days"],
  "error": "Bad Request"
}

Solution: Reduce the date range to 365 days or less.

400 Bad Request - Invalid Station Code ​

json
{
  "statusCode": 400,
  "message": ["Invalid station code: XYZ"],
  "error": "Bad Request"
}

Solution: Use valid station codes (DMX, JXD, KCX, MKX).

400 Bad Request - Same Origin and Destination ​

json
{
  "statusCode": 400,
  "message": ["Departure and arrival airports cannot be the same"],
  "error": "Bad Request"
}

Solution: Use different station codes for departure and arrival.

Use Cases ​

1. Building a Route Selector ​

javascript
// After fetching routes, create origin/destination selectors
const { routes } = await getRoutes();

// Get unique stations
const stations = [...new Set(routes.flatMap(r => [r.origin, r.destination]))];

// Populate selectors
populateStationSelector('origin-select', stations);
populateStationSelector('destination-select', stations);

2. Date Picker with Availability ​

javascript
// When user selects a route, fetch calendar availability
async function onRouteChange(origin, destination) {
  const today = new Date();
  const nextMonth = new Date(today.getFullYear(), today.getMonth() + 1, 0);

  const availability = await getCalendarAvailability({
    startDate: formatDate(today),
    endDate: formatDate(nextMonth),
    departureAirport: origin,
    arrivalAirport: destination,
  });

  renderCalendarWithAvailability(availability);
}

3. Price Comparison by Date ​

javascript
// Find cheapest date in range
function findCheapestDate(availability: DateAvailability[]) {
  const available = availability.filter(d => d.available);
  return available.reduce((min, day) =>
    day.minPrice.SAR < min.minPrice.SAR ? day : min
  );
}
