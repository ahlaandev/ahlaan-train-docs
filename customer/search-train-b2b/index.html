B2B Train Search Guide (11+ Passengers) ​

This guide explains how B2B customers can search for train tickets for groups of 11 or more passengers on the HHR API.

Quick Overview ​

FeatureDescription
Search EndpointPOST /api/v1/ota/search
AuthenticationRequired (B2B approved users only)
Trip TypesOne-way or Round-trip
Passenger TypesAdult, Child, Infant
Cabin ClassesBusiness (C), Economy (Y)
Minimum Passengers11 ticketed passengers (adults + children)

Base URL ​

/api/v1

B2B vs B2C Search ​

Key Differences ​

FeatureB2C (1-10 passengers)B2B (11+ passengers)
AuthenticationOptional (guest allowed)Required (B2B approved)
Passenger LimitMax 10 (adults + children)No limit
PricingStandard HHR pricingTariff vs HHR comparison
Pricing SourceHHR StandardTARIFF, HHR_DISCOUNTED, or HHR_STANDARD

B2B Pricing Logic ​

When you search with 11+ passengers, the system automatically compares two pricing sources and returns the better price:

if HHR price >= Tariff price:
    Use Tariff price + B2B markup
    pricingSource = "TARIFF"

else if HHR price < Tariff price:
    Use HHR price - B2B markup (discount)
    pricingSource = "HHR_DISCOUNTED"

else if no Tariff exists:
    Use HHR price + B2B markup
    pricingSource = "HHR_STANDARD"

Pricing Sources:

  • TARIFF - Special tariff pricing is better than HHR
  • HHR_DISCOUNTED - HHR price is better than tariff (discount applied)
  • HHR_STANDARD - No tariff exists, standard HHR pricing with markup

  • Infants don't count toward the threshold
  • Authentication as B2B approved user required

Understanding the B2B Response ​

B2B Pricing Object ​

The key difference in B2B search is the b2bPricing object in each fare:

json
{
  "b2bPricing": {
    "adultPrice": 150.00,        // Final price per adult (SAR)
    "childPrice": 112.50,        // Final price per child (SAR)
    "infantPrice": 0,            // Final price per infant (usually 0)
    "totalPrice": {
      "SAR": 1950.00             // Total for all passengers (SAR)
    },
    "pricingSource": "TARIFF",   // TARIFF, HHR_DISCOUNTED, or HHR_STANDARD
    "comparison": {
      "hhrTotalPrice": 2500.00,   // Original HHR price
      "tariffTotalPrice": 1900.00, // Tariff price (null if no tariff)
      "markupApplied": 50,       // Markup added (positive) or discount (negative)
      "savings": 550.00          // How much was saved vs the alternative
    }
  }
}

Pricing Source Examples ​

Example 1: TARIFF pricing (Tariff is cheaper) ​

json
{
  "b2bPricing": {
    "pricingSource": "TARIFF",
    "comparison": {
      "hhrTotalPrice": 2500.00,
      "tariffTotalPrice": 1900.00,
      "markupApplied": 50,
      "savings": 550.00
    }
  }
}

Explanation: Tariff price (1900) + markup (50) = 1950 SAR Savings: 2500 (HHR) - 1950 (Final) = 550 SAR

Example 2: HHR_DISCOUNTED pricing (HHR is cheaper) ​

json
{
  "b2bPricing": {
    "pricingSource": "HHR_DISCOUNTED",
    "comparison": {
      "hhrTotalPrice": 4600.00,
      "tariffTotalPrice": 5000.00,
      "markupApplied": -50,
      "savings": 450.00
    }
  }
}

Explanation: HHR price (4600) - markup/discount (50) = 4550 SAR Savings: 5000 (Tariff) - 4550 (Final) = 450 SAR

Example 3: HHR_STANDARD pricing (No tariff exists) ​

json
{
  "b2bPricing": {
    "pricingSource": "HHR_STANDARD",
    "comparison": {
      "hhrTotalPrice": 3000.00,
      "tariffTotalPrice": null,
      "markupApplied": 50
    }
  }
}

Explanation: HHR price (3000) + markup (50) = 3050 SAR Reason: No tariff exists for this route/class/type

Round-Trip Search ​

For round trips, include returnDate and set tripType to ROUND_TRIP:

json
{
  "origin": "DMX",
  "destination": "MKX",
  "departureDate": "2026-02-01",
  "returnDate": "2026-02-05",
  "tripType": "ROUND_TRIP",
  "passengerQuantities": {
    "adults": 15,
    "children": 0,
    "infants": 0
  }
}

Response includes:

  • outbound_flights - Departure options (origin → destination) with B2B pricing
  • return_flights - Return options (destination → origin) with B2B pricing

Note: Each segment (outbound and return) gets independent B2B pricing comparison.

Code Examples ​

JavaScript/TypeScript (fetch) ​

typescript
interface B2BSearchParams {
  origin: string;
  destination: string;
  departureDate: string;
  tripType: 'ONE_WAY' | 'ROUND_TRIP';
  returnDate?: string;
  passengerQuantities: {
    adults: number;  // Must be >= 11 when combined with children
    children?: number;
    infants?: number;
  };
}

interface B2BPricing {
  adultPrice: number;
  childPrice: number;
  infantPrice: number;
  totalPrice: { SAR: number };
  pricingSource: 'TARIFF' | 'HHR_DISCOUNTED' | 'HHR_STANDARD';
  comparison: {
    hhrTotalPrice: number;
    tariffTotalPrice: number | null;
    markupApplied: number;
    savings?: number;
  };
}

interface B2BFare {
  type: 'SAVER' | 'PROMO' | 'STANDARD';
  isRefundable: boolean;
  fareReference: string;
  pricingSource: 'TARIFF' | 'HHR_DISCOUNTED' | 'HHR_STANDARD';
  pricePerAdult: {
    amount: number;
    currency: string;
  };
  totalPrice: {
    SAR: number;
    IDR: number;
  };
  b2bPricing: B2BPricing;
  ptcFareBreakdown?: PtcFareBreakdown[];
}

async function searchB2BTrains(
  params: B2BSearchParams,
  accessToken: string
): Promise<any> {
  const response = await fetch('/api/v1/ota/search', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${accessToken}`,
    },
    body: JSON.stringify(params),
  });

  if (!response.ok) {
    throw new Error(`B2B search failed: ${response.statusText}`);
  }

  return await response.json();
}

// Example: Search for 15 passengers from Madinah to Makkah
const results = await searchB2BTrains({
  origin: 'DMX',
  destination: 'MKX',
  departureDate: '2026-02-01',
  tripType: 'ONE_WAY',
  passengerQuantities: {
    adults: 15,
    children: 0,
  },
}, 'your-access-token');

// Display results with B2B pricing breakdown
results.outbound_flights.forEach((flight) => {
  console.log(`Train ${flight.flightInfo.flightNumber}`);
  console.log(`  ${flight.flightInfo.departureAirport} → ${flight.flightInfo.arrivalAirport}`);
  console.log(`  Departure: ${flight.flightInfo.departure}`);
  console.log(`  Arrival: ${flight.flightInfo.arrival}`);
  console.log(`  Duration: ${flight.flightInfo.duration}`);

  flight.classes.forEach((cls) => {
    console.log(`  ${cls.cabinClass} Class:`);

    cls.fares.forEach((fare) => {
      const b2b = fare.b2bPricing;
      console.log(`    ${fare.type} (${fare.pricingSource}):`);
      console.log(`      Price per adult: ${b2b.adultPrice} SAR`);
      console.log(`      Price per child: ${b2b.childPrice} SAR`);
      console.log(`      Total price: ${b2b.totalPrice.SAR} SAR`);

      // Show comparison details
      console.log(`      Price comparison:`);
      console.log(`        HHR price: ${b2b.comparison.hhrTotalPrice} SAR`);
      if (b2b.comparison.tariffTotalPrice) {
        console.log(`        Tariff price: ${b2b.comparison.tariffTotalPrice} SAR`);
      }
      if (b2b.comparison.savings) {
        console.log(`        Your savings: ${b2b.comparison.savings} SAR`);
      }
    });
  });
});

B2B Pricing Calculation Examples ​

Example 1: TARIFF Pricing (15 Adults) ​

Scenario:

  • 15 adults, Economy class
  • HHR price: 250 SAR/adult = 3,750 SAR total
  • Tariff price: 150 SAR/adult = 2,250 SAR total
  • B2B markup: 50 SAR

Calculation:

Tariff total: 15 × 150 = 2,250 SAR
HHR total: 15 × 250 = 3,750 SAR

Since HHR (3,750) >= Tariff (2,250):
Final price = Tariff + Markup = 2,250 + 50 = 2,300 SAR
Price per adult = 2,300 / 15 = 153.33 SAR

pricingSource = "TARIFF"
savings = 3,750 - 2,300 = 1,450 SAR

Example 2: HHR_DISCOUNTED Pricing (12 Adults, 3 Children) ​

Scenario:

  • 12 adults + 3 children, Business class
  • HHR price: 350 SAR/adult, 262.50 SAR/child = 4,987.50 SAR total
  • Tariff price: 400 SAR/adult, 300 SAR/child = 5,700 SAR total
  • B2B markup: 50 SAR

Calculation:

HHR total: (12 × 350) + (3 × 262.50) = 4,987.50 SAR
Tariff total: (12 × 400) + (3 × 300) = 5,700 SAR

Since HHR (4,987.50) < Tariff (5,700):
Final price = HHR - Markup = 4,987.50 - 50 = 4,937.50 SAR
Price per adult = 350 - (50/15) ≈ 346.67 SAR
Price per child = 262.50 SAR

pricingSource = "HHR_DISCOUNTED"
savings = 5,700 - 4,937.50 = 762.50 SAR

Example 3: HHR_STANDARD Pricing (11 Adults) ​

Scenario:

  • 11 adults, Economy class
  • HHR price: 200 SAR/adult = 2,200 SAR total
  • Tariff: No tariff exists for this route
  • B2B markup: 50 SAR

Calculation:

HHR total: 11 × 200 = 2,200 SAR
Tariff: Not available

Final price = HHR + Markup = 2,200 + 50 = 2,250 SAR
Price per adult = 2,250 / 11 = 204.55 SAR

pricingSource = "HHR_STANDARD"

Next Steps After B2B Search ​

Once you find a suitable train:

  1. Calculate final price using /ota/book/calculate
  2. Create GROUP booking using /ota/book with bookingType: "GROUP"
  3. Receive booking code to manage/cancel booking

For B2B bookings, use the GROUP booking type to provide passenger quantities instead of individual passenger details. Names can be added later using the modify booking endpoint.

Troubleshooting ​

No B2B pricing in response ​

  • Verify you have at least 11 ticketed passengers (adults + children)
  • Check you're authenticated as a B2B approved user
  • Infants don't count toward the 11 passenger threshold

pricingSource shows "HHR_STANDARD" instead of "TARIFF" ​

  • This means no tariff exists for the specific route/class/trip type
  • The system falls back to standard HHR pricing with markup

Why is markupApplied negative? ​

  • Negative markup means a discount was applied
  • This happens when HHR price is cheaper than tariff price
  • pricingSource will be "HHR_DISCOUNTED"

What is the savings field? ​

  • Shows how much was saved by choosing the better pricing option
  • For TARIFF: savings = HHR price - (Tariff price + markup)
  • For HHR_DISCOUNTED: savings = Tariff price - (HHR price - markup)
