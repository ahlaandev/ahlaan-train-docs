B2C Train Search Guide ​

This guide explains how B2C customers can search for train tickets on the HHR API.

Search EndpointPOST /api/v1/ota/search
AuthenticationOptional (guest users can search)
Trip TypesOne-way or Round-trip
Passenger TypesAdult, Child, Infant
Cabin ClassesBusiness (C), Economy (Y)

Main Search Endpoint ​

Search for available trains between two stations.

http
POST /ota/search
Content-Type: application/json

Request Body ​

json
{
  "origin": "DMX",
  "destination": "MKX",
  "departureDate": "2026-02-01",
  "tripType": "ONE_WAY",
  "passengerQuantities": {
    "adults": 2,
    "children": 1,
    "infants": 0
  }
}

Request Parameters ​

ParameterTypeRequiredDescription
originstringYesOrigin station code (DMX, JXD, KCX, MKX)
destinationstringYesDestination station code
departureDatestringYesDeparture date (YYYY-MM-DD), cannot be in past
tripTypestringYesONE_WAY or ROUND_TRIP
returnDatestringNo*Return date for round trips (YYYY-MM-DD)
passengerQuantitiesobjectYesPassenger breakdown (see below)

* Required for ROUND_TRIP

Passenger Quantities ​

json
{
  "adults": 2,      // Age 12+
  "children": 1,    // Age 2-11
  "infants": 0      // Age 0-1 (travel free)
}

Default: { "adults": 1, "children": 0, "infants": 0 }

Passenger Limits (B2C):

  • Maximum 10 passengers total (adults + children)
  • Infants don't count toward the limit

Understanding the Response ​

Flight Info Structure ​

FieldDescriptionExample
flightNumberTrain/flight number"0080"
marketingAirlineMarketing airline code"HHR"
operatingAirlineOperating airline code"HHR"
operatingFlightNumberOperating flight number"0080"
departureAirportOrigin station code"DMX"
arrivalAirportDestination station code"MKX"
departureDateTimeISO 8601 departure datetime"2026-02-01T08:00:00.000+03:00"
arrivalDateTimeISO 8601 arrival datetime"2026-02-01T10:25:00.000+03:00"
durationFlight duration"2h 25m"
resBookDesigCodeBooking class code"Y" (Economy) or "C" (Business)

Note: The departure and arrival fields are deprecated. Use departureDateTime and arrivalDateTime instead.

Fare Types ​

TypeFare Reference PrefixRefundableDescription
SAVERNOTCANCEL*NoBudget fare, non-refundable, lowest price
PROMOOTAPENALTY*YesDiscounted fare with strikethrough pricing
STANDARDE* or B*YesRegular fare, fully refundable

Refundability Check:

  • isRefundable: false → Cannot be cancelled
  • isRefundable: true → Can be cancelled (may have fee)

originalFinalPrice Field ​

The originalFinalPrice field is used to show the price before any promotional discounts:

Fare TypeoriginalFinalPrice.SARoriginalFinalPrice.IDRDescription
PROMONon-null numberNon-null numberPrice of STANDARD fare (for comparison)
SAVERnullnullNo original price (already lowest)
STANDARDnullnullNo original price (base fare)

Example:

json
{
  "type": "PROMO",
  "fareReference": "OTAPENALTY",
  "finalPrice": {
    "SAR": 408.61,
    "IDR": 1823218
  },
  "originalFinalPrice": {
    "SAR": 640.29,
    "IDR": 2856814
  }
}

In this example:

  • PROMO fare final price: SAR 408.61
  • Original price (STANDARD fare): SAR 640.29
  • Discount: SAR 231.68 (36% off)

Display Recommendation:

  • Show the finalPrice as the current price
  • Show originalFinalPrice with strikethrough styling to indicate the discount
  • Calculate and display the percentage savings: (originalFinalPrice - finalPrice) / originalFinalPrice × 100

Fare Preferences Metadata ​

The metadata.farePreferences field provides guidance on which fare type should be displayed as the default option for each cabin class:

json
{
  "metadata": {
    "farePreferences": {
      "preferences": [
        {
          "cabinClass": "BUSINESS",
          "defaultFareType": "PROMO"
        },
        {
          "cabinClass": "ECONOMY",
          "defaultFareType": "STANDARD"
        }
      ]
    }
  }
}

How to Use:

  • BUSINESS class → Pre-select PROMO fares in the UI
  • ECONOMY class → Pre-select STANDARD fares in the UI

Notes:

  • Fare preferences are configured by admins and may change over time
  • Always check metadata.farePreferences for the current defaults
  • The default fare type may not always be available (sold out, not offered)
  • Fallback to STANDARD if the default type is unavailable

Price Breakdown (ptcFareBreakdown) ​

The ptcFareBreakdown array provides detailed pricing per passenger type:

json
{
  "passengerType": "ADT",      // "ADT", "CHD", or "INF"
  "passengerTypeLabel": "Adult",
  "quantity": 2,
  "perPassenger": {
    "SAR": {
      "totalFare": 224.25,     // Base fare + markup (before tax)
      "totalTax": 33.64,       // Tax/VAT amount
      "totalPrice": 257.89     // totalFare + totalTax (per passenger)
    },
    "IDR": { ... }
  },
  "subtotal": {
    "SAR": {
      "totalFare": 448.50,     // For all passengers of this type
      "totalTax": 67.28,
      "totalPrice": 515.78
    },
    "IDR": { ... }
  }
}
ComponentDescription
totalFareBase fare + markup (before tax)
totalTaxTax/VAT amount
totalPriceFinal price (totalFare + totalTax)
subtotalCombined total for all passengers of this type

Important Notes:

  • Infants (INF) typically have totalFare: 0, totalTax: 0, totalPrice: 0 (travel free)
  • finalPrice in the fare object equals the sum of all subtotal.totalPrice values

Exchange Rate ​

json
{
  "buyRate": "4470",      // SAR to IDR buy rate
  "sellRate": "4491",     // SAR to IDR sell rate (used for pricing)
  "fetchedAt": "2026-01-26T21:00:01.894Z"
}

Currency Conversion Formula:

priceIDR = priceSAR × sellRate

Example:

2162507 ≈ 481.52 × 4491

Round-Trip Search ​

For round trips, include returnDate and set tripType to ROUND_TRIP:

json
{
  "origin": "DMX",
  "destination": "MKX",
  "departureDate": "2026-02-01",
  "returnDate": "2026-02-05",
  "tripType": "ROUND_TRIP",
  "passengerQuantities": {
    "adults": 1,
    "children": 0,
    "infants": 0
  }
}

Response includes:

  • outbound_flights - Departure options (origin → destination)
  • return_flights - Return options (destination → origin)

Note: Round-trip is essentially two one-way searches combined. Each segment is priced independently.

Calculate Booking Price ​

http

Content-Type: application/json

Pricing Formula ​

totalPrice = baseFare + totalTax

Where:
- baseFare = OTA base price + markup
- totalTax = Tax calculated on baseFare

Code Examples ​

JavaScript/TypeScript (fetch) ​

typescript
interface TrainSearchParams {
  origin: string;
  destination: string;
  departureDate: string;
  tripType: 'ONE_WAY' | 'ROUND_TRIP';
  returnDate?: string;
  passengerQuantities?: {
    adults?: number;
    children?: number;
    infants?: number;
  };
}

interface SearchResponse {
  metadata: {
    tripType: string;
    totalFlights: number;
    passengers: {
      adults: number;
      children: number;
      infants: number;
    };
  };
  outbound_flights: Flight[];
  return_flights: Flight[] | null;
  exchangeRate: {
    buyRate: string;
    sellRate: string;
    fetchedAt: string;
  };
}

interface Flight {
  flightInfo: {
    flightNumber: string;
    marketingAirline: string;
    departureAirport: string;
    arrivalAirport: string;
    departure: string;
    arrival: string;
    duration: string;
    resBookDesigCode: string;
  };
  classes: Class[];
}

interface Class {
  cabinClass: 'BUSINESS' | 'ECONOMY';
  availableSeats: number;
  fares: Fare[];
}

interface Fare {
  type: 'SAVER' | 'PROMO' | 'STANDARD';
  isRefundable: boolean;
  fareReference: string;
  pricePerAdult: {
    SAR: { amount: number; originalAmount: number };
    IDR: { amount: number; originalAmount: number };
  };
  finalPrice: {
    SAR: number;
    IDR: number;
  };
  originalFinalPrice: {
    SAR: number | null;
    IDR: number | null;
  };
  ptcFareBreakdown?: PtcFareBreakdown[];
}

interface PtcFareBreakdown {
  passengerType: 'ADT' | 'CHD' | 'INF';
  passengerTypeLabel: string;
  quantity: number;
  perPassenger: {
    SAR: { totalFare: number; totalTax: number; totalPrice: number };
    IDR: { totalFare: number; totalTax: number; totalPrice: number };
  };
  subtotal: {
    SAR: { totalFare: number; totalTax: number; totalPrice: number };
    IDR: { totalFare: number; totalTax: number; totalPrice: number };
  };
}

async function searchTrains(params: TrainSearchParams): Promise<SearchResponse> {
  const response = await fetch('/api/v1/ota/search', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      origin: params.origin,
      destination: params.destination,
      departureDate: params.departureDate,
      tripType: params.tripType,
      returnDate: params.returnDate,
      passengerQuantities: {
        adults: params.passengerQuantities?.adults ?? 1,
        children: params.passengerQuantities?.children ?? 0,
        infants: params.passengerQuantities?.infants ?? 0,
      },
    }),
  });

  if (!response.ok) {
    throw new Error(`Search failed: ${response.statusText}`);
  }

  return await response.json();
}

// Example: Search for trains from Madinah to Makkah
const results = await searchTrains({
  origin: 'DMX',
  destination: 'MKX',
  departureDate: '2026-02-01',
  tripType: 'ONE_WAY',
  passengerQuantities: {
    adults: 2,
    children: 1,
  },
});

// Display results
results.outbound_flights.forEach((flight) => {
  console.log(`Train ${flight.flightInfo.flightNumber}`);
  console.log(`  ${flight.flightInfo.departureAirport} → ${flight.flightInfo.arrivalAirport}`);
  console.log(`  Departure: ${flight.flightInfo.departure}`);
  console.log(`  Arrival: ${flight.flightInfo.arrival}`);
  console.log(`  Duration: ${flight.flightInfo.duration}`);
  console.log(`  Class: ${flight.flightInfo.resBookDesigCode}`);

  flight.classes.forEach((cls) => {
    console.log(`  ${cls.cabinClass} Class:`);

    cls.fares.forEach((fare) => {
      console.log(`    ${fare.type}: ${fare.finalPrice.SAR} SAR`);
      console.log(`      Refundable: ${fare.isRefundable}`);

      // Display price breakdown if available
      if (fare.ptcFareBreakdown) {
        fare.ptcFareBreakdown.forEach((ptc) => {
          console.log(`      ${ptc.passengerTypeLabel} (${ptc.quantity}x):`);
          console.log(`        Base fare: ${ptc.perPassenger.SAR.totalFare} SAR`);
          console.log(`        Tax: ${ptc.perPassenger.SAR.totalTax} SAR`);
          console.log(`        Total: ${ptc.perPassenger.SAR.totalPrice} SAR`);
        });
      }
    });
  });
});

Station CodesMust be valid codes (DMX, JXD, KCX, MKX)

Next Steps After Search ​

Once you find a suitable train:

  1. Calculate final price using /ota/book/calculate
  2. Create booking using /ota/book (requires authentication)
  3. Receive booking code to manage/cancel booking

See API Reference for booking endpoint details.

Troubleshooting ​

No results returned ​

  • Check station codes are valid (DMX, JXD, KCX, MKX)
  • Verify departure date is not in the past
  • Try different dates or routes

Price changed during booking ​

  • Prices are fetched in real-time from external API
  • Use /ota/book/calculate with refreshPrice: true for latest pricing

Missing ptcFareBreakdown ​

  • ptcFareBreakdown is only available for authenticated admin users
  • B2C users should use finalPrice for the total amount

Infant pricing shows 0 ​

  • This is correct behavior - infants travel free
  • Infants are still counted in the booking for seat allocation
