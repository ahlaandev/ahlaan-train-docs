B2B Registration Guide ​

This guide explains how to register as a B2B (Business-to-Business) partner to access group booking discounts, tariff pricing, and organization wallet features.

Quick Overview ​

FeatureB2C (Individual)B2B (Business)
Booking TypeRegular (1-10 passengers)Group (11+ passengers)
PricingStandard ratesTariff-based pricing with discounts
PaymentPay per bookingOrganization wallet (SAR)
InvoiceIndividual invoicesOrganization invoices
ManagementPersonal accountMulti-user organization

Who Can Apply ​

  • Travel agencies
  • Tour operators
  • Corporate travel departments
  • Individual travel agents

Requirements:

  • Valid Indonesian Business Identification Number (NIB) - 13 digits
  • Valid Taxpayer Identification Number (NPWP) - 15 digits
  • NIB document in PDF format (max 10MB)

Registration Paths ​

There are two ways to become a B2B partner:

Path 1: New B2B Registration ​

For new users who don't have an existing HHR account.

What happens:

  • New user account is created with B2B role
  • Account is passwordless (uses OTP authentication)
  • Email and phone are auto-confirmed from application

Path 2: B2C to B2B Upgrade ​

For existing B2C customers who want to upgrade to business features.

What happens:

  • Existing account is linked to the B2B application
  • On approval: role changes from B2C to B2B
  • Personal wallet balance is transferred to new organization wallet
  • Booking history is preserved

API Endpoints ​

Base URL ​

/api/v1

1. Submit B2B Application (New User) ​

For new users without an existing account. No authentication required.

Endpoint: POST /auth/b2b/register

Request Body:

json
{
  "companyName": "PT Travel Indonesia",
  "companyAddress": "Jl. Sudirman No. 123, Jakarta Pusat",
  "nib": "1234567890123",
  "npwp": "123456789012345",
  "companyPhone": "+628123456789",
  "companyEmail": "info@travelindonesia.com",
  "picName": "John Doe",
  "picEmail": "john.doe@travelindonesia.com",
  "picPhone": "+6281234567890"
}

Response: 201 Created

json
{
  "id": "01h5x9k2y3",
  "companyName": "PT Travel Indonesia",
  "status": "PENDING",
  "submittedAt": "2026-01-31T10:00:00Z",
  "message": "Application submitted successfully. Please upload your NIB document for review.",
  "nextSteps": [
    "Upload NIB document (PDF format, max 10MB)",
    "Wait for admin review",
    "You will be notified once your application is approved or rejected"
  ]
}

What happens:

  • New user account is created with B2B role
  • Email and phone are auto-confirmed
  • Passwordless account (uses OTP for login)
  • Application status is set to PENDING

2. Upgrade B2C to B2B ​

For existing B2C customers upgrading to business account. Requires authentication.

Endpoint: POST /auth/b2b/upgrade

Authentication: Required (JWT token)

http
Authorization: Bearer <your-jwt-token>

Request Body: Same as new registration

json
{
  "companyName": "PT Travel Indonesia",
  "companyAddress": "Jl. Sudirman No. 123, Jakarta Pusat",
  "nib": "1234567890123",
  "npwp": "123456789012345",
  "companyPhone": "+628123456789",
  "companyEmail": "info@travelindonesia.com"
}

Response: 201 Created

json
{
  "id": "01h5x9k2y3",
  "companyName": "PT Travel Indonesia",
  "status": "PENDING",
  "submittedAt": "2026-01-31T10:00:00Z",
  "message": "Application submitted successfully. Please upload your NIB document for review."
}

What happens:

  • Application is linked to your existing B2C account
  • On approval: your role changes from B2C to B2B
  • Your personal wallet balance is transferred to the new organization wallet
  • Your booking history is preserved

3. Upload NIB Document ​

Upload the NIB document (PDF only, max 10MB). Required before approval.

Endpoint: POST /auth/b2b/register/:id/upload-nib

Authentication: Optional (application ID from registration is sufficient)

Request: multipart/form-data

FieldTypeRequiredDescription
fileFileYesPDF file (max 10MB, valid PDF structure required)

Example with cURL:

bash
curl -X POST \
  https://api.example.com/api/v1/auth/b2b/register/01h5x9k2y3/upload-nib \
  -F "file=@nib-document.pdf"

Response: 200 OK

5. Resubmit Rejected Application ​

Edit and resubmit a rejected application with corrections.

Endpoint: PATCH /auth/b2b/application

Authentication: Required (JWT token)

Request Body: Include only fields you want to update

json
{
  "companyAddress": "Jl. Thamrin No. 456, Jakarta Pusat",
  "companyPhone": "+628987654321"
}

Response: 200 OK

json
{
  "id": "01h5x9k2y3",
  "companyName": "PT Travel Indonesia",
  "status": "PENDING",
  "submittedAt": "2026-01-31T10:00:00Z",
  "resubmittedAt": "2026-02-01T14:30:00Z",
  "submissionCount": 2,
  "rejectionReason": null,
  "message": "Application resubmitted successfully"
}

Notes:

  • Only applications with REJECTED status can be resubmitted
  • You can also upload a new NIB document if needed
  • Submission count is incremented

Post-Approval ​

Once your application is approved, you'll receive:

1. Organization Code ​

A unique code is auto-generated from your company name:

  • "PT Travel Indonesia" → PTIN01
  • "Hajar Travel Umrah" → HTUH42

This code is used for:

  • Invoice references
  • Support inquiries
  • Organization identification

2. Organization Wallet ​

  • Currency: SAR (Saudi Riyal)
  • Initial balance: 0
  • For B2C upgrades: your personal wallet balance is transferred here

Code Examples ​

JavaScript/TypeScript (New Registration) ​

typescript
async function registerB2B(companyData: {
  companyName: string;
  companyAddress: string;
  nib: string;
  npwp: string;
  companyPhone: string;
  companyEmail: string;
}) {
  // Step 1: Submit application
  const response = await fetch('/api/v1/auth/b2b/register', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(companyData)
  });

  const application = await response.json();
  console.log('Application ID:', application.id);

  // Step 2: Upload NIB document
  const formData = new FormData();
  formData.append('file', nibFileInput.files[0]);

  await fetch(`/api/v1/auth/b2b/register/${application.id}/upload-nib`, {
    method: 'POST',
    body: formData
  });

  return application;
}

JavaScript/TypeScript (B2C Upgrade) ​

typescript
async function upgradeToB2B(
  accessToken: string,

  });

FAQ ​

Q: How long does approval take? ​

A: Typically 1-2 business days after NIB document is uploaded.

Q: Can I book while waiting for approval? ​

A: Yes, you can continue using B2C features. Once approved, you'll have B2B access.

Q: What if my NIB document is rejected? ​

A: You'll receive a rejection reason. Fix the issue and resubmit via PATCH endpoint.

Q: Can I change my company name after approval? ​

A: No, organization details are fixed after creation. Contact support for special cases.

Q: What happens to my B2C bookings after upgrade? ​

A: All booking history is preserved and accessible.

Q: Can I revert from B2B to B2C? ​

A: No, this is a one-way upgrade. Contact support if you have specific needs.

Q: Do I need a password for my new B2B account? ​

A: No, B2B accounts are passwordless. Use OTP authentication via email or phone.

Troubleshooting ​

"NIB already exists" error ​

  • Another application or account is using this NIB
  • Contact support if you believe this is an error

"NPWP already exists" error ​

  • Another application is using this NPWP
  • Verify your NPWP is correct

"User already has a B2B account" error ​

  • Your email or phone is already linked to a B2B account
  • Each user can only have one B2B account

Upload fails ​

  • Ensure file is valid PDF
  • Check file size is under 10MB
  • Verify PDF is not corrupted or password-protected

Application stuck in PENDING ​

  • Ensure NIB document is uploaded
  • Check your email/WhatsApp for rejection notifications
  • Contact support if pending for more than 3 business days
