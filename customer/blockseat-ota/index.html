BlockSeat OTA Guide (Wholesale) ​

This guide covers the BlockSeat search + calculate endpoints. BlockSeat is ota/* restricted to wholesale (≥11 seated pax), priced supplier − reducer. The supplier is searched with the REAL requested passenger counts under the wholesale credential (no 1/1/1 probe), so the per-passenger fare is the actual wholesale group rate; the reducer pipeline (per-passenger allocation, whole-riyal integer floor, seat cap) then applies. The supplier returns ≥11 fares only for departures ≥72h (within 72h is not searchable/bookable). Wholesale differences vs custom-OTA:

  • ECONOMY-only (policy, 2026-06-20). BlockSeat sells ECONOMY only. Non-ECONOMY (BUSINESS) cabins are omitted from search results entirely, and a BUSINESS-class leg is rejected with 400 at both book/calculate and booking creation. This is a permanent product rule (no toggle). Already-stored BlockSeat BUSINESS bookings (if any predate the rule) are untouched — the rule is forward-only and applies to new search/calculate/book requests.
  • Reducer pricing for ECONOMY. The ECONOMY fare is priced supplier price − priceReducer, sourced from the shared CustomRoutePrice table (the same reducer config promo/custom-OTA uses, keyed on (origin, destination, tripClass)). The reducer is shared between wholesale and promo on a given route+class — they cannot diverge.
  • STANDARD fares, no strikethrough. Every fare is a plain STANDARD fare; originalFinalPrice is 0 and there is no per-adult originalAmount.
supplierPerPax_T = ptcfareBreakdowns[T].totalFare.amount   (raw wholesale supplier fare, real-count search ⇒ group per-pax rate)
perPax_T  = floor( max(0, supplierPerPax_T − priceReducer × (supplierPerPax_T / supplierPerPax_ADT)) )   (whole riyal)
finalPrice = Σ legs Σ pax  perPax_T × realCount            (exact sum of integer per-pax shares)
fare type  = "STANDARD"   ;   originalFinalPrice = { SAR: 0, IDR: 0, USD: 0 }   (no strikethrough)

The priceReducer is an adult discount allocated across passengers by per-pax fare ratio, identical to the custom-OTA ECONOMY algorithm (allocateCustomPerPax REDUCER mode). A route with no active BlockSeat reducer prices at the raw supplier fare (reducer 0), still floored per passenger. The supplier's own VAT stays inside totalFare (cost, not a tax we levy) — there is no HHR markup or HHR tax on a BlockSeat fare.

BlockSeat is reducer-only — never a surcharge. BlockSeat reads the shared CustomRoutePrice.priceReducer, which custom-OTA can now set negative (a surcharge). Wholesale is out of surcharge scope, so the resolver clamps any negative shared reducer to 0: a route configured with a negative reducer for the promo flow prices at raw supplier cost on BlockSeat, never above it.

Host. BlockSeat is served on blockseat.ahlaan.co.id (custom-OTA is on mitra.ahlaan.co.id, the main OTA on tiket.ahlaan.co.id). Host routing is handled by the reverse proxy (Traefik); the API itself is not host-gated for BlockSeat's own pricing.

No special B2B pricing on BlockSeat. All Special Custom B2B Pricing — the route priceReducer, the exchangeRateReducer (including its new BUSINESS SAR→IDR conversion), and the ECONOMY price cap — is scoped exclusively to the promo host mitra.ahlaan.co.id (configurable via PROMO_BASE_DOMAIN). BlockSeat (blockseat.ahlaan.co.id) and the main OTA (tiket.ahlaan.co.id) always use standard pricing, even for an enrolled organization. BlockSeat's own supplier − reducer ECONOMY pricing (above) is a separate mechanism and is unaffected.

1. Search Trains ​

POST /api/v1/blockseat-ota/search

Guards: optional auth. Throttle: 20/60s. Body is the same SearchTrainDto as custom-OTA (origin, destination, departureDate, returnDate?, tripType, passengerQuantities).

Minimum seated passengers (enforced here too). Search enforces the same wholesale floor as calculate/book: a request whose seated count (adults + children; infants excluded) is below the minimum (default 11, configurable via BLOCKSEAT_MIN_PASSENGERS) is rejected with 400. A sub-minimum group cannot browse BlockSeat fares it could never book.

The supplier is searched with the real requested passenger counts (always ≥11 seated) under the wholesale credential — no 1/1/1 probe — so each fare's per-passenger rate is the actual wholesale group rate (returned for departures ≥72h). Each cabin carries a bookable flag: false when its remaining availableSeats cannot fit the requested seated passengers (adults + children; infants are lap). Every returned fare is a STANDARD fare priced supplier − reducer.

ECONOMY-only. BlockSeat results contain ECONOMY cabins only; any BUSINESS cabin the supplier returns is dropped before the response. A flight offered solely in BUSINESS therefore returns no bookable BlockSeat class.

Request

json
{
  "origin": "MKX",
  "destination": "DMX",
  "departureDate": "2026-07-19",
  "tripType": "ONE_WAY",
  "passengerQuantities": { "adults": 10, "children": 5, "infants": 0 }
}

2. Calculate Booking Price ​

POST /api/v1/blockseat-ota/book/calculate

Guards: optional auth + B2B-approved. Throttle: 10/60s. Body is the same CalculateBookingPriceDto as custom-OTA (route + chosen fareId / returnFareId + passengerQuantities).

Wholesale rules enforced here (the commit step):

  • Minimum seated passengers. A request whose seated count (adults + children; infants excluded) is below the wholesale floor (default 11, configurable via BLOCKSEAT_MIN_PASSENGERS) is rejected with 400.
  • Seat cap. A request whose seated count exceeds the cabin's remaining availableSeats is rejected with code INSUFFICIENT_SEATS (per leg).

The response is the same shape as /custom-ota/book/calculate (pricing.{SAR,IDR,USD}, trip, ptcFareBreakdown), priced supplier − reducer for every class.

Request

json
{
  "origin": "MKX",
  "destination": "DMX",
  "departureDate": "2026-07-19",
  "tripType": "ONE_WAY",
  "fareId": "SAB2MINECO",
  "flightSegment": {
    "flightNumber": "20003",
    "marketingAirline": "HHR",
    "operatingAirline": "HHR",
    "operatingFlightNumber": "20003",
    "departureAirport": "MKX",
    "arrivalAirport": "DMX",
    "departureDateTime": "2026-07-19T10:00:00.000+03:00",
    "arrivalDateTime": "2026-07-19T11:00:00.000+03:00",
    "resBookDesigCode": "Y"
  },
  "passengerQuantities": { "adults": 10, "children": 5, "infants": 0 }
}

A below-minimum request (seated < 11) returns 400; a request exceeding a cabin's availableSeats returns INSUFFICIENT_SEATS.

Errors ​

BlockSeat reuses the unified OTA error envelope (OtaErrorResponseDto). Branch on code / category / retryable. Notable codes: below-minimum seated passengers (400) and INSUFFICIENT_SEATS.
