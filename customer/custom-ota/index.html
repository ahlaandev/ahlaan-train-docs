Custom OTA Guide ​

This guide covers the Custom OTA endpoints, which provide train search and pricing using scraper-collected price data instead of live OTA API calls. This enables offering prices on routes where direct OTA availability may be limited.

Quick Overview ​

FeatureDescription
Search TrainsPOST /api/v1/custom-ota/search — Search using scraper prices
Calculate PricePOST /api/v1/custom-ota/book/calculate — Get final price
Price SourceScraper price records + CustomRoutePrice reducer
Tax / MarkupNo tax, no markup — price is raw SAR amount
CurrenciesSAR, IDR (via exchange rate), USD (fixed 3.75)

How It Differs from Regular OTA ​

AspectRegular OTACustom OTA
Price sourceLive OTA API callScraper-collected price data
AvailabilityReal-time seat countsStatic (shows 99 available seats)
BookingFull booking flowCalculate only (no booking endpoint)
TaxApplied per OTA rulesNo tax (always 0)
MarkupApplied per system configNo markup
Fare referenceOTA fare code (e.g., E080821000PM0)Route code (e.g., JXD:MKX)
CustomRoutePriceFull feature (sellingPrice or priceReducer)Uses only priceReducer when configured

Note: Custom OTA uses useSellingPrice=false mode in CustomRoutePrice. When you configure a CustomRoutePrice entry for a custom-ota route, set useSellingPrice=false and provide only the priceReducer value. The sellingPrice and capitalPrice fields are optional and can be omitted.

Data Flow ​

┌──────────────┐     ┌──────────────────┐     ┌───────────────┐
│  Scraper     │────▶│  ScraperPrice    │────▶│  Custom OTA   │
│  (external)  │     │  Records (DB)    │     │  Service      │
└──────────────┘     └──────────────────┘     └───────┬───────┘
                                                       │
                              ┌──────────────────┐     │
                              │  CustomRoute     │────▶│  Effective
                              │  Price (DB)      │     │  Price calc
                              │  .priceReducer   │     │
                              └──────────────────┘     └───────┬───┘
                                                               │
                                                               ▼
                                                       ┌───────────────┐
                                                       │  Exchange     │
                                                       │  Rate Service │
                                                       │  (SAR→IDR)    │
                                                       └───────────────┘

Pricing formula:

effectivePrice = max(0, meanPricePerAdult - priceReducer)

Where:

  • meanPricePerAdult comes from the latest ScraperPriceRecord for that route/class/date
  • priceReducer comes from an active CustomRoutePrice entry (0 if none exists)

1. Search Trains ​

Search for available trains using scraper price data. Returns flights grouped by cabin class.

http
POST /custom-ota/search
Content-Type: application/json

Request Body ​

json
{
  "origin": "JXD",
  "destination": "MKX",
  "departureDate": "2026-06-15",
  "tripType": "ONE_WAY",
  "passengerQuantities": {
    "adults": 2,
    "children": 1,
    "infants": 0
  }
}

returnDatestringNo*Return date for round trips
tripTypeenumYesONE_WAY or ROUND_TRIP

2. Calculate Booking Price ​

Calculate the final price for a specific fare. Requires B2B approved account.

Content-Type: application/json
Authorization: Bearer <token>

Request Body (ONE_WAY) ​

{

  "tripType": "ONE_WAY",
  "departureDate": "2026-06-15",

    "adults": 2,
    "children": 1,
    "infants": 0

Request Fields ​

FieldTypeRequiredDescription
fareIdstringYesRoute code from search (e.g., JXD:MKX)
tripTypeenumYesONE_WAY or ROUND_TRIP
departureDatestringYesDeparture date (YYYY-MM-DD)

returnDatestringNo*Return date

Pricing Rules ​

Custom OTA pricing is simple — no tax, no markup:

Passenger TypePrice Rule
AdulteffectivePrice (full price)
ChildeffectivePrice × 0.5 (50% discount)
Infant0 (free)

Effective price calculation:

effectivePrice = max(0, meanPricePerAdult - priceReducer)
  • meanPricePerAdult — latest scraper price for this route/class/date
  • priceReducer — from active CustomRoutePrice (0 if no active entry)
  • The result is never negative (floored at 0)

No additional charges:

  • totalTax is always 0
  • No markup is applied
  • baseFare equals totalPrice

Example Calculation ​

Scraper price (mean):     200 SAR
CustomRoutePrice reducer:  20 SAR
──────────────────────────────
Effective adult price:    180 SAR

2 adults × 180 SAR      = 360 SAR
1 child  ×  90 SAR      =  90 SAR
──────────────────────────────
Total (SAR)              = 450 SAR

Exchange Rate ​

Prices are provided in three currencies:

CurrencyConversion
SARBase currency
IDRSAR × sellRate (from ExchangeRateService)
USDSAR ÷ 3.75 (fixed peg)

The exchange rate is fetched from the live rate in the system (same source as the regular OTA). If no rate is available, the request will fail with a 400 Bad Request.

Search (ONE_WAY) ​

bash
curl -X POST /api/v1/custom-ota/search \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{
    "origin": "JXD",
    "destination": "MKX",
    "departureDate": "2026-06-15",
    "tripType": "ONE_WAY",
    "passengerQuantities": { "adults": 2, "children": 1, "infants": 0 }
  }'

Search (ROUND_TRIP) ​

bash
curl -X POST /api/v1/custom-ota/search \

    "destination": "MKX",
    "departureDate": "2026-06-15",

Error Responses ​

400 Bad Request — Exchange Rate Unavailable ​

json
{
  "statusCode": 400,
  "message": "Exchange rate not available",
  "error": "Bad Request"
}

400 Bad Request — Invalid Fare Reference ​

json
{
  "statusCode": 400,
  "message": "Invalid fare reference: \"INVALID\". Expected format: ORIGIN:DESTINATION (e.g., JXD:MKX)",
  "error": "Bad Request"
}

404 Not Found — No Scraper Prices ​

json
{
  "statusCode": 404,
  "message": "No scraper prices found for route \"JXD:MKX\" on 2026-06-15. Please search again.",
  "error": "Not Found"
}

json
{
  "statusCode": 401,
  "message": "Unauthorized",
  "error": "Unauthorized"
}

json
{
