Guest Guides ​

Welcome to the HHR guest guides. These guides explain how to use OTA features without authentication.

Available Guides ​

GuideDescription
OTA GuideSearch trains, calculate prices, and download tickets without authentication

What Guests Can Do ​

As a guest (unauthenticated user), you can:

  • Search Trains - Find available trains between HHR stations
  • Calculate Prices - Get accurate pricing with taxes and fees
  • View Routes - See all available train routes
  • Check Calendar - Find available dates for your journey
  • Download Tickets - Access tickets via public links (if you have the booking ID)

Guest Limitations ​

To create a booking, you need to:

  1. Register as a Customer - Create an account
  2. Complete Booking - Use authenticated endpoints
