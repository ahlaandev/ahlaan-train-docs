OTA Guest Booking Guide ​

This guide explains how guests (unauthenticated users) can search for trains, create bookings, and complete payments on the HHR API.

Quick Overview ​

FeatureDescription
View RoutesGET /api/v1/ota/routes - Get available train routes
Calendar AvailabilityGET /api/v1/ota/calendar-availability - Check available dates
Availability RangePOST /api/v1/ota/availability-range - Get seat availability across dates
Search TrainsPOST /api/v1/ota/search - Search available trains with pricing
Calculate PricePOST /api/v1/ota/book/calculate - Get final price before booking
Create BookingPOST /api/v1/ota/book - Create booking (guest supported)
Get Payment GatewaysGET /api/v1/invoice/:id/available-gateways - Get available payment methods
Generate PaymentPOST /api/v1/invoice/:id/generate-payment - Create payment link
Download TicketsGET /api/v1/ota/bookings/:id/tickets - Public ticket download
AuthenticationNot required for search, booking, and payment endpoints

Base URL ​

/api/v1

Availability Range (Seat Availability with Pricing) ​

http
POST /ota/availability-range
Content-Type: application/json

Request Body ​

json
{
  "origin": "MKX",
  "destination": "DMX"
}

Request Parameters ​

ParameterTypeRequiredDescription
originstringYesOrigin station code (DMX, MKX, JXD, KCX)
destinationstringYesDestination station code
isB2BbooleanNoEnable B2B pricing mode (default: false)

Notes:

  • The date range is automatically generated (7 days from today). Results are cached for 30 minutes.
  • B2B pricing uses tariff comparison for bookings with more than 10 passengers.

Search Trains (Guest) ​

Search for available trains between stations. This endpoint works for both guests and authenticated users.

http
POST /ota/search
Content-Type: application/json

Request Body ​

json
{
  "origin": "DMX",
  "destination": "MKX",
  "departureDate": "2026-02-15",
  "tripType": "ONE_WAY",
  "passengerQuantities": {
    "adults": 2,
    "children": 1,
    "infants": 0
  }
}

Request Parameters ​

ParameterTypeRequiredDescription
originstringYesOrigin station code (DMX, MKX, JXD, KCX)
destinationstringYesDestination station code
departureDatestringYesDeparture date (YYYY-MM-DD)
returnDatestringNo*Return date for round trips
tripTypestringYesONE_WAY or ROUND_TRIP
passengerQuantitiesobjectYesPassenger breakdown

* Required for ROUND_TRIP

Passenger Quantities ​

json
{
  "adults": 2,      // Age 12+ (required, min 0)
  "children": 1,    // Age 2-11 (optional, default 0)
  "infants": 0      // Age 0-1, travel free (optional, default 0)
}

Passenger Limits:

  • REGULAR bookings: Maximum 10 passengers (adults + children)
  • GROUP bookings: More than 10 passengers (adults + children)
  • Infants don't count toward the limit for booking type determination
  • Booking type is automatically determined based on passenger count

Public Ticket Download ​

Guests can download tickets using the booking ID (from confirmation email or URL) without authentication.

http
GET /ota/bookings/:id/tickets

Path Parameters ​

ParameterTypeRequiredDescription
idstringYesBooking ID (UUID format)

Response ​

Success (200 OK): Returns a ZIP file containing PDF tickets with QR codes for each passenger

Content-Type: application/zip
Content-Disposition: attachment; filename=ABC123.zip

Requirements:

  • Booking must be in TICKETED status
  • Tickets are generated from the OTA system

Download Specific Ticket ​

Download a specific ticket by ticket number:

Code Examples ​

JavaScript/TypeScript (fetch) ​

typescript
// Search for trains
async function searchTrains(params: {
  origin: string;
  destination: string;
  departureDate: string;
  tripType: 'ONE_WAY' | 'ROUND_TRIP';
  passengerQuantities: { adults: number; children?: number; infants?: number };
}) {
  const response = await fetch('/api/v1/ota/search', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(params),
  });

  if (!response.ok) {
    throw new Error(`Search failed: ${response.statusText}`);
  }

  return await response.json();
}

// Calculate price
async function calculatePrice(bookingData: any) {
  const response = await fetch('/api/v1/ota/book/calculate', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(bookingData),
  });

  if (!response.ok) {
    throw new Error(`Calculation failed: ${response.statusText}`);
  }

  return await response.json();
}

// Download tickets
async function downloadTickets(bookingId: string): Promise<Blob> {
  const response = await fetch(`/api/v1/ota/bookings/${bookingId}/tickets`);
  
  if (!response.ok) {
    throw new Error(`Download failed: ${response.statusText}`);
  }

  return await response.blob();
}

// Example usage
async function example() {
  // Search trains
  const searchResults = await searchTrains({
    origin: 'DMX',
    destination: 'MKX',
    departureDate: '2026-02-15',
    tripType: 'ONE_WAY',
    passengerQuantities: { adults: 2, children: 1 },
  });

  console.log(`Found ${searchResults.outboundFlights.length} flights`);

  // Display first flight
  const flight = searchResults.outboundFlights[0];
  console.log(`Train ${flight.flightInfo.flightNumber}`);
  console.log(`${flight.flightInfo.departureAirport} → ${flight.flightInfo.arrivalAirport}`);
  console.log(`Departure: ${flight.flightInfo.departureDateTime}`);

  // Show available fares
  flight.classes.forEach((cls: any) => {
    console.log(`\n${cls.cabinClass} Class:`);
    cls.fares.forEach((fare: any) => {
      console.log(`  ${fare.type}: ${fare.finalPrice.SAR} SAR (${fare.isRefundable ? 'Refundable' : 'Non-refundable'})`);
    });
  });
}

Benefits of Registration ​

  1. Wallet Payments - Instant confirmation without payment links
  2. Booking History - View all past and upcoming bookings
  3. Saved Passengers - Quick booking with saved passenger details
  4. Loyalty Points - Earn points on bookings (if applicable)

Register After Guest Booking ​

If you created a guest booking with your email, you can register and your previous bookings will be automatically linked to your account.

See Registration & Login Guide for details.

Validation Rules ​

RuleDescription
Departure DateCannot be in the past
Return DateMust be equal to or after departure date
Passenger CountMinimum 1 total (adults + children > 0)
Booking TypeAuto-determined: ≤10 passengers = REGULAR, >10 passengers = GROUP
Station CodesMust be valid HHR station codes
Email NormalizationAll emails are automatically lowercased

Error Responses ​

400 Bad Request - Invalid Parameters ​

json
{
  "statusCode": 400,
  "message": ["departureDate should not be in the past"],
  "error": "Bad Request"
}

400 Bad Request - Guest Contact Missing ​

json
{
  "statusCode": 400,
  "message": "Guest booking requires email or phone in guestContact field",
  "error": "Bad Request"
}

403 Forbidden - Contact Mismatch ​

json
{
  "statusCode": 403,
  "message": "Contact information does not match booking",
  "error": "Forbidden"
}

404 Not Found - No Schedules ​

json
{
  "statusCode": 404,
  "message": "No schedules found for the given criteria",
  "error": "Not Found"
}

429 Too Many Requests - Rate Limit ​

json
{
  "statusCode": 429,
  "message": "Throttled",
  "error": "Too Many Requests"
}
